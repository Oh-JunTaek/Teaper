# Windows 테스트 설치 안내

이 문서는 **코드 서명 전 테스트 설치 파일**을 위한 안내입니다. 모바일에서 이 작업을 지시하는 경우에도 패키지 생성은 진행할 수 있으나, 실제 설치·Ollama 연결·PDF 저장 최종 확인은 Windows PC에서 해야 합니다.

## 설치 전 확인

| 항목 | 확인 내용 |
|---|---|
| 운영체제 | Windows 10 22H2 이상을 초기 지원 기준으로 권장 |
| 저장공간 | 앱과 로컬 모델을 위한 여유 공간 확인 |
| Ollama | [공식 설치 페이지](https://ollama.com/download/windows)에서 직접 설치 |
| 네트워크 | 모델 최초 다운로드 때만 필요; 문항 생성은 로컬 모델 실행 시 PC 안에서 처리 |
| 시험 보안 | 공유 PC·개인 클라우드 동기화 폴더가 아닌 학교 지침에 맞는 저장 위치 사용 |

## 설치 및 첫 실행

테스트 설치 파일은 Windows 코드 서명 전 버전이므로 보안 경고가 나타날 수 있다. 공식 배포 경로에서 받은 파일인지 먼저 확인하고, 테스트 참여자로서 신뢰할 수 있는 파일일 때만 설치한다. 코드 서명 없이 배포한 앱은 운영체제 경고가 표시될 수 있으므로, 정식 공개 전에는 Windows 코드 서명을 적용한다.[1] [2]

앱을 열면 ‘로컬 준비 상태’에서 Ollama 실행 여부를 확인한다. 실행 중인 모델이 없으면 PC 사양에 따라 제안된 모델을 보고, 저장공간과 라이선스를 확인한 후 ‘준비하기’를 선택한다. 자료 등록 → 기출 등록 → 문항 생성 → 검수 → 승인 문항 DOCX·PDF·CSV 출력 순서로 확인한다.

### 테스트 설치 파일 무결성 확인

| 항목 | 값 |
|---|---|
| 파일명 | `teacher-assessment-local-test-0.1.0-beta.3-setup.exe` |
| 파일 크기 | 약 100 MB |
| SHA-256 | `827bf29e757534ff54f652d6775c346fe3cf08c1b051dbaacef302aa08dc41ab` |

Windows PowerShell에서 `Get-FileHash "파일경로" -Algorithm SHA256`을 실행해 위 값과 일치하는지 확인할 수 있다. 값이 다르면 설치하지 말고 새 파일을 다시 받아야 한다.

## PC에서 수행할 최종 확인표

| 단계 | 예상 결과 |
|---|---|
| 설치 파일 실행 | 설치 경로를 선택할 수 있고 바탕화면·시작 메뉴 바로가기가 생성됨 |
| 첫 실행 | ‘로컬 모델 전용’ 안내와 런타임 상태가 표시됨 |
| Ollama 연결 | 실행 중인 모델 목록 또는 권장 모델 준비 버튼이 표시됨 |
| 자료·기출 등록 | 앱을 재시작한 뒤에도 SQLite 로컬 저장소에 남아 있음 |
| 문항 생성 | 외부 API 동의 없이 로컬 Ollama 응답이 검수함에 저장됨 |
| 문서 출력 | 시험지와 정답·해설 DOCX가 분리되고, PDF는 운영체제 인쇄 대화상자가 열림 |
| 종료·재실행 | 파일을 내보낸 뒤에도 원본 문항과 검수 상태가 유지됨 |

## 현재 제한

이 파일은 **테스트용**이며 Windows 코드 서명·자동 업데이트·복구 설치 프로그램은 아직 적용하지 않았다. 개발 중인 파일을 임의 배포하지 말고, 설치 실패·보안 경고·Ollama 실행 오류가 있으면 화면 문구와 Windows 버전을 함께 기록해 전달한다.
