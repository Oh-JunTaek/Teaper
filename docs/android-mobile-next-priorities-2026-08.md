# EunmaStudio Android 모바일 다음 우선순위

## 현재 판단

Android 파일럿은 Gemma 4 E2B 기본·E4B 선택, 앱 전용 모델 저장, 백그라운드 다운로드, 자료 등록, 문항 생성·검수·DOCX/PDF 공유, 온디바이스 채팅, 카드형 홈까지 구현됐다. 다만 실제 S25+에서 모델 실행·비행기 모드·문서 공유·키보드·발열을 한 번에 확인하기 전에는 기능 확장보다 **실기기 안전성 확인**이 우선이다.

> **권장 순서:** 저녁 실기기 테스트 통과 → P1 보안·복구 → P2 교사 작업 속도 → P3 배포 준비.

## 우선순위 제안

| 우선순위 | 기능 | 교사에게 주는 가치 | 운영·보안 경계 | 착수 조건 |
|---|---|---|---|---|
| P0 | S25+ 일괄 현장 시험 | 실제 다운로드·오프라인·채팅·문서 공유의 신뢰 확인 | 비민감 샘플만 사용, 원문·개인정보 수집 금지 | alpha.6 설치 |
| P1-1 | 앱 잠금과 로컬 암호화 | 휴대폰 분실·공용 기기에서 출제 자료 노출 감소 | 생체 인증 또는 앱 잠금 암호, Android Keystore 기반 키 관리, 잠금 해제 정보 외부 전송 금지 | E2B 안정성 통과 |
| P1-2 | 암호화 백업·복구 | 기기 교체·삭제 사고에서 로컬 자료·문항·대화 복구 | 교사가 지정한 암호로 암호화, 모델 파일·원본 시험 파일은 기본 제외, 자동 클라우드 백업 금지 | 앱 잠금 설계 확정 |
| P1-3 | 자료·문항 삭제와 보관 기한 | 시험 전 자료의 잔존 위험 감소 | 일괄 삭제·공유 캐시 즉시 정리·삭제 확인 절차, 불필요한 사용 이력 미보관 | P1-1과 함께 |
| P2-1 | 채팅 답변을 문항 작업으로 보내기 | 질의응답에서 만든 아이디어를 자료·문항·검수 흐름으로 전환 | 교사 확인 전 자동 승인 금지, 출처 없는 답변은 근거 요청 상태로 표시 | 채팅 E2B 실기기 통과 |
| P2-2 | 자료 원문 뷰어와 페이지 이동 | 근거·쪽수 확인을 빠르게 수행 | 원본은 앱 전용 저장소·선택 URI 권한 범위 안에서만 열기, 외부 업로드 없음 | PDF 처리 실기기 통과 |
| P2-3 | 문항 초안 편집·버전 되돌리기 | 교사가 생성 결과를 빠르게 다듬고 수정 이력을 비교 | 수정 이력은 기기 안에만 보관, 승인 전 결과만 내보내기 | 문항 생성·검수 통과 |
| P2-4 | 작업 중단 복구 | 전화·알림·화면 회전 뒤 작성 중 내용 손실 감소 | 임시 초안은 앱 전용 저장소에만 보관하고 교사가 삭제 가능 | 키보드·채팅 안정성 통과 |
| P3-1 | 접근성·다국어·큰 글자 대응 | 다양한 교사가 안정적으로 사용 | 색 대비·터치 영역·스크린리더·큰 글자 우선, 교사 데이터 수집 없음 | P2 핵심 흐름 안정화 |
| P3-2 | 서명된 AAB와 Play 내부 테스트 | 설치 경고를 줄이고 제한된 교사 시험 배포 | Data safety·개인정보 처리방침·모델 NOTICE·내부 테스터 관리, 원격 모델 전송 없음 | P0·P1 완료 |
| P3-3 | 선택적 익명 품질 신호 | 기능 문제를 최소 정보로 파악 | 기본 비활성, 문항·자료·대화·기기 식별자 미수집, 교사 명시 동의가 있을 때만 집계 | 운영 정책·화면 동의 확정 |

## 지금 구현하지 않는 항목

아래 기능은 초기 로컬 우선·시험 보안 원칙과 충돌하거나 서비스 범위를 불필요하게 넓히므로, 현재는 보류한다.

| 보류 항목 | 보류 이유 |
|---|---|
| 원본 자료·대화·출제 문항의 자동 클라우드 동기화 | 출제 예정 문항과 교사 자료의 외부 노출 면이 증가함 |
| 모바일 개인 API 키 입력 | Android 로컬 모델 전용 원칙과 충돌하며 키 관리·비용·외부 전송 동의가 복잡해짐 |
| 답변·문항의 자동 승인 또는 자동 배포 | 교육 평가 책임과 교사 최종 검수 원칙에 맞지 않음 |
| 광고·행동 기반 분석 | 개인정보를 수집하지 않는 초기 운영 원칙과 맞지 않음 |

## 다음 착수 제안

저녁 일괄 테스트에서 **E2B 다운로드·비행기 모드 채팅·PDF/DOCX 공유·하단 레이아웃**이 통과하면, 다음 구현은 **P1-1 앱 잠금과 로컬 암호화**를 권장한다. 시험 출제 보조 서비스에서 이동 기기의 분실·무단 열람 위험을 먼저 낮추고, 그 뒤 암호화 백업·자료 뷰어·문항 편집으로 확장하는 순서가 적절하다.
