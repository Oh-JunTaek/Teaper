# Android alpha.18 빌드 검증 기록

## 구현 범위

자료 준비 카드는 `SourcesActivity` 전용 자료실로 이동한다. 자료실 안에서 직접 작성·파일 업로드·공식 원문 링크·기존 자료 확인을 수행하며, 기존 홈 팝업의 빈 버튼 문제를 우회한다.

대화는 최근 의미 있는 사용자 질문을 기기 안에서 제목으로 추천한다. 기존 대화도 목록을 열 때 자동 제목을 한 번 갱신하며, 교사가 **편집**으로 저장한 제목은 이후 자동 갱신하지 않는다. 대화 기록은 카드형 목록·제목 편집·현재 대화 삭제를 제공한다.

## 검증 결과

`testDebugUnitTest`와 `assembleDebug`는 `BUILD SUCCESSFUL`로 완료되었다. 설치 APK는 `versionCode=18`, `versionName=0.1.0-alpha.18`이며 SHA-256은 `8a1e3916e3b5462b72176c4c30bbff050373c8e65a9a94da25b820b6b0616eef`이다. S25+에서 자료실 화면·파일 업로드·기존 대화 제목 갱신·제목 수정·대화 삭제를 확인해야 한다.
