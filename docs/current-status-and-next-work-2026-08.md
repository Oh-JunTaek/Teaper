# EunmaStudio 문제 출제 워크스페이스: 현재 상태 및 후속 과제

**작성일:** 2026-08-21  
**대상 버전:** `b8fd3a35`  
**운영 단계:** 초대 기반 교사 파일럿  
**서비스 제공자:** EunmaStudio

> 이 서비스는 시험 문항을 자동 완성하거나 정답을 보증하는 도구가 아닙니다. 교사가 교육과정·학교 자료·기출 유형을 확인하고, 문항 생성과 검수 이력을 관리하도록 돕는 **자료 기반 출제 보조 작업공간**입니다.

## 1. 한눈에 보는 현재 상태

현재 웹 서비스는 화학 I 파일럿을 기준으로 문항 생성부터 승인·내보내기까지의 작업 흐름을 제공한다. 중등 과학·수학, 고등 통합과학·공통수학 등은 **제한 파일럿**으로 열려 있으며, 대수·미적분Ⅰ·확률과 통계 및 일부 고등 과학 과목은 공식 문서 확인만 가능한 **준비 중** 상태로 유지한다. 마지막 검증에서 TypeScript 검사와 Vitest 단위 테스트 **68개**가 통과했다.

| 영역 | 현재 상태 | 운영상 의미 |
|---|---|---|
| 문항 생성·검수 | 구현·배포 | 교사 자료와 선택된 공식 자료를 연결하여 생성하고, 승인·수정·반려 이력을 남김 |
| 자료·기출 관리 | 구현·배포 | 참고 자료와 기출을 교사별 작업공간에서 등록·삭제·선택 가능 |
| 공식 자료 | 구현·배포 | 교육과정·총론·평가 자료의 링크·메타데이터를 과목별로 제공 |
| 수학 안전장치 | 중등 수학 1차 적용 | 계산 가능한 일부 유형에서 결정론적 대조 후 불일치를 보류 |
| AI 제공자 | 구현·배포 | 개발용 관리형 AI, 개인 Gemini·OpenAI·Claude, 로컬 실행 준비 경로 지원 |
| 초대·권한·정책 | 구현·배포 | 공유 링크 파일럿 게이트, 교사/관리자 분리, 운영 정책·사용량 집계 제공 |
| 기관·정식 공개 | 미구현 또는 운영 설계 단계 | 다기관 테넌트, 감사 체계, 정식 상용 운영 절차는 아직 완료되지 않음 |

## 2. 구현 완료 기능

### 2.1 교사 출제 작업 흐름

교사는 참고 자료를 파일 또는 웹 링크로 등록하고, 개인 작업공간에 기출문제를 출처·연도·문항 번호·페이지·출제 의도·정답·해설과 함께 관리할 수 있다. PDF는 텍스트 추출을 우선 적용하고, 이미지형 자료에는 내용 읽기를 보조 적용한다. 파일 저장 키는 ASCII 안전 형식으로 분리하여 한글 파일명 업로드 문제를 줄였으며, 원본 파일명은 교사용 화면에 보존한다.

| 기능 | 구현 내용 | 교사 화면에서의 결과 |
|---|---|---|
| 참고 자료 | 파일·웹 링크 등록, 내용 추출, 삭제, 과목·단원·연도·유형 관리 | 자료를 생성 근거로 선택하고 원본 위치를 확인 |
| 기출문제 | 개인 작업공간 등록·수정·선택, PDF 연결 | 출처·문항 번호·페이지를 근거 이력에서 확인 |
| 문항 생성 | 과목·단원·난이도·유형·배점·문항 수 입력 | 자료를 바탕으로 문항·정답·해설·검수 초안 생성 |
| 진행 표시 | 자료 확인 → 문항 생성 → 답·해설 검증 → 검수함 준비 | 작업 단계가 진행 중임을 표시 |
| 시각 문항 | 표·그래프 구조 데이터 및 SVG 렌더링 | 그래프 설명문만 남지 않도록 실제 시각 요소 표시 |
| 검수 | 승인·수정·반려, 사유 기록, 근거·검증·실행 이력 표시 | 교사가 최종 판단과 수정 이력을 보존 |
| 내보내기 | 승인 문항 CSV 내보내기 | 후속 편집·관리용 파일 생성 |

### 2.2 자료와 공식 기준 체계

공식 원문을 무단 복제하지 않고, 확인 가능한 **공식 링크와 메타데이터**를 카탈로그로 제공한다. 교사는 자료별 사용 여부를 직접 선택하며, 선택된 항목만 생성 기록에 연결된다. 이 구조는 2022 개정 교육과정의 총론과 각 교과 교육과정, KICE 학생평가지원포털의 성취기준·평가 자료를 출제 기준 경로로 활용하는 방향과 맞춘다.[1] [2]

| 자료 층 | 제공 범위 | 현재 구현 상태 |
|---|---|---|
| 교육과정 총론 | 적용 시기와 공통 운영 기준 | 공통 공식 자료로 제공 |
| 과목별 교육과정 | 중등 과학·수학, 고등 과학·수학, 화학 I | 선택한 학교급·교과·과목에 따라 필터링 |
| 성취기준·평가기준 | KICE 검색 경로, 에듀넷 성취수준 자료실 | 공통 공식 자료로 제공 |
| 학생평가 도구 | 수행평가·서논술형·채점기준 참고 경로 | 공통 공식 자료로 제공 |
| 학교 자료 | 평가계획·수업 자료·학기 운영표 | 교사별 격리, 삭제 및 원본 위치 기록 |

최근에는 **대수·미적분Ⅰ·확률과 통계**의 2022 개정 교육과정 링크를 추가했다. 다만 이 세 과목은 문서가 있다는 이유만으로 생성 가능 상태로 올리지 않았다. 단원별 계산·조건 검수와 교사 검수 문항 묶음이 마련되기 전까지 서버에서도 생성을 차단한다.

### 2.3 AI 제공자와 전송 경계

문항 생성은 개발·파일럿 단계에서 관리형 AI를 기본값으로 사용할 수 있으며, 개인이 자신의 키를 등록해 Gemini·OpenAI·Claude를 선택할 수도 있다. 개인 키는 암호화해 저장하고, 외부 제공자 사용 전에는 전송될 요청 범위와 동의를 확인한다. 외부 제공자 장애가 발생해도 문항 원문을 임의로 다른 제공자에게 전송하지 않는 원칙을 적용한다.

| 제공 방식 | 현재 지원 | 주요 경계 |
|---|---|---|
| 개발용 관리형 AI | 사용 가능 | 운영자가 익명 일별 합계만 확인, 정식 배포 기본값으로 확정하지 않음 |
| 개인 API | Gemini·OpenAI·Claude 지원 | 암호화 저장, 요청별 외부 전송 동의 필요 |
| 로컬 AI | Ollama 중심 준비·설치 안내·상태 확인 경로 | 웹 서비스가 교사 PC의 파일·모델에 직접 접근하지 않음 |
| 데스크톱 로컬 모드 | 데이터 경계·브리지·저장 계약 구현 기반 | 일반 교사용 설치 패키지와 운영 배포는 별도 마일스톤 |

### 2.4 신뢰성과 과목 공개 경계

일반적인 AI 검토만으로 수학 문항이 무오류라고 판단하지 않는다. 중등 수학의 수치 계산·일차식·비례·기초 통계는 제한된 계산 사양을 결정론적으로 해석해 정답과 대조한다. 불일치하면 자동 검증을 보류하며, 해석·조건 누락·정의역·난이도·교육과정 적합성은 여전히 교사가 검수해야 한다.

| 준비 상태 | 과목 예시 | 생성 정책 |
|---|---|---|
| 파일럿 검증 | 화학 I | 기존 파일럿 흐름에서 생성 가능 |
| 제한 파일럿 | 중등 과학·수학, 통합과학1·2, 공통수학1·2, 화학 | 생성 가능하나 자료·공식 기준·검수 확인 필수 |
| 준비 중 | 대수, 미적분Ⅰ, 확률과 통계, 물리학, 생명과학, 지구과학 | 자료 등록·공식 문서 확인만 제공, 서버에서 생성 차단 |

대시보드에는 이 상태를 기준으로 과목을 골라 보는 필터가 있다. 또한 중등 수학 계산 확인기에는 유리수 계산, 일차방정식, 비례식, 평균의 대표 조건을 이용한 회귀 검수 묶음이 포함된다. 이는 계산기 기능의 후퇴를 찾기 위한 최소 검증이며, 수학 전 범위의 품질 보증은 아니다.

### 2.5 보안·개인정보·운영 기반

공유 링크 파일럿에서는 초대 코드가 확인된 브라우저만 서비스에 진입할 수 있고, Google 로그인 외에 게스트 로그인도 제공한다. 교사와 관리자의 서버 접근 권한을 분리했고, 일반 교사에게는 사용자 관리 기능을 노출하지 않는다. 관리자 목록도 이메일·최근 로그인 기록을 최소화해 개인정보 노출을 줄였다.

| 분야 | 구현 내용 | 현 단계의 한계 |
|---|---|---|
| 접근 통제 | 초대 코드, 서명 쿠키, Google·게스트 로그인, 역할 분리 | 개별 초대·계정별 제한은 더 강화 필요 |
| 문항 보안 | 교사별 자료·기출·문항 접근 분리, 원본 위치 기록 | 보존기간·다운로드 통제·유출 대응 훈련은 미완료 |
| 개인정보 | 원문·프롬프트·파일명·IP를 제외한 관리형 AI 일별 합계 | 익명 이용 통계는 정책·전문가 검토 후 활성화 필요 |
| 사용량 | 생성·검증·내용 추출의 성공·실패·제한 응답을 관리자 조회 | 게스트별 관리형 AI 일일 상한은 아직 없음 |
| 운영 정책 | EunmaStudio 운영 정책, 출시 전 체크리스트, 책임 매핑 | 정식 출시 전 법률·개인정보 전문 검토 필요 |

## 4. 권장 실행 순서

다음 작업은 기능 개수보다 **문항 보안과 신뢰성**을 먼저 줄이는 순서로 진행하는 것이 적절하다.

| 순서 | 권장 작업 | 산출물 |
|---:|---|---|
| 1 | 게스트/초대 계정별 관리형 AI 일일 생성 한도와 초대 회수 | 파일럿 남용·비용 위험을 통제하는 운영 화면과 정책 |
| 2 | 화학 I·중등 수학 교사 검수 문항 회귀 묶음 | 모델·프롬프트 변경 전 통과해야 하는 비공개 기준 |
| 3 | 대수·미적분Ⅰ·확률과 통계의 단원별 계산·조건 확인 | 준비 중 과목을 제한 파일럿으로 올릴 근거 |
| 4 | 성취기준 매핑과 PDF 기출 문항 분할 보조 | 자료 추적성과 검수 효율 향상 |
| 5 | 개별 초대·보존/삭제·사고 대응을 포함한 보안 운영 점검 | 정식 공개 또는 기관 도입의 최소 운영 기반 |

## 5. 운영자가 지금 결정하면 좋은 사항

| 결정 항목 | 선택지 | 권장 방향 |
|---|---|---|
| 파일럿 계정 방식 | 공용 게스트 유지 / 초대별 계정 | 시험 문항 보안을 위해 **초대별 계정**으로 전환 |
| 관리형 AI 한도 | 무제한 / 일별 제한 / 개인 API 우선 | 파일럿은 낮은 일별 제한, 이후 개인·로컬 AI 우선 |
| 다음 과목 | 고등 수학 3과목 / 물리학·생명과학·지구과학 / 사용성 개선 | 신뢰성 기반을 재사용할 수 있는 **고등 수학 3과목**부터 |
