# EunmaStudio Android 파일럿: Galaxy S25+ 현장 시험 절차

이 문서는 **Gemma 4 E2B를 우선**으로 하는 Android 파일럿의 실기기 확인 절차다. 실제 시험 문항, 학생 개인정보, 기관 내부 자료는 사용하지 않는다. 샘플 텍스트·공개 PDF·비민감 이미지로만 확인한다.

## 2026-08 저녁 일괄 테스트 범위

아래 표는 alpha.7 기준으로 한 번에 실행하는 **실기기 확인 항목**이다. 각 행은 `통과`, `실패`, `보류` 중 하나로 표시하고 실패 시 실제 문항 원문 대신 오류 문구·발생 단계·화면만 남긴다.

| 순서 | 시험 항목 | 통과 기준 |
|---:|---|---|
| 1 | alpha.7 업데이트 설치 | 기존 앱 위에 설치되며 자료·모델 상태가 예기치 않게 초기화되지 않음 |
| 2 | 홈 카드 보기 | 기본 2열 앨범형 카드가 시스템 하단 바 위에서 끝나며, 교사 작성 선호에서 일자형 전환 후 재실행해도 선택 유지 |
| 3 | E2B 백그라운드 다운로드 | 알림에 용량·퍼센트·속도가 표시되고 다른 앱으로 이동해도 진행되며, 설치 버튼을 다시 눌러도 중복 다운로드가 시작되지 않음 |
| 4 | 모델 유지 | E2B 완료 후 앱을 종료·재실행해도 다시 다운로드하지 않고 선택·준비 가능 |
| 5 | 온디바이스 채팅 | 일반 질문, 등록 자료 참고 전환, 새 대화·대화 삭제가 동작하며 키보드가 열린 상태의 작성 바가 키보드 바로 위에 고정됨 |
| 6 | 오프라인 채팅 | E2B 준비 후 비행기 모드에서 짧은 질의응답이 이어지고 외부 연결 오류가 발생하지 않음 |
| 7 | 자료 처리 | TXT·텍스트형 PDF·이미지를 각각 등록했을 때 기기 안에서 내용 확인이 되고 PDF는 쪽수 근거가 표시됨 |
| 8 | 출제·검수·공유 | 자료 기반 문항 생성·검수·승인을 거쳐 DOCX와 인쇄용 PDF를 기기 공유 시트로 열 수 있음 |
| 9 | E2B 안정성 | 약 10분 사용에서 강제 종료·심한 발열·비정상 배터리 소모가 없음 |
| 10 | E4B 선택 시험 | 충분한 공간에서만 선택하고, 응답 속도·발열·배터리·메모리를 E2B와 비교해 기록함 |
| 11 | 앱 잠금 | 교사 작성 선호에서 앱 잠금을 켠 뒤 다른 앱으로 이동·복귀했을 때 자료가 가려지고, 생체 인증 또는 기기 잠금 인증 성공 뒤에만 내용이 다시 보임 |

> **중단 기준:** 심한 발열, 앱 반복 종료, 배터리 급감, 모델 파일 손상 또는 오류 반복이 있으면 E4B 시험을 중단하고 E2B 상태·오류 문구를 기록한다.

## 시작 전 조건

| 항목 | 확인 방법 | 기록할 값 |
|---|---|---|
| 앱 버전 | 모델 관리 화면 또는 설치 파일명 확인 | `0.1.0-alpha.3` 이상 |
| 기기 | 설정 → 휴대전화 정보 | Galaxy S25+ / Android 버전 |
| 네트워크 | 안정적인 Wi-Fi 연결 | 연결 여부 |
| 배터리 | 모델 다운로드 전 | 시작 퍼센트 |
| 저장 공간 | 설정 → 디바이스 케어 또는 앱 화면 | 시작 여유 공간 |
| 알림 | E2B 다운로드 시작 시 허용 | 허용 여부 |

## E2B 다운로드와 백그라운드 지속 확인

1. 앱의 **모델 관리** 카드에서 E2B 다운로드를 시작한다. 알림 권한을 묻는 경우 허용한다.
2. 화면에 연결 상태 또는 `받은 GB / 전체 GB`, 퍼센트, 속도가 나타나는지 확인한다.
3. 다운로드가 시작된 뒤 홈 화면으로 돌아가고, 다른 앱을 1~2분 사용한다. 앱을 강제 종료하거나 Android 작업 관리자에서 중지하지는 않는다.
4. 상단 고정 알림의 받은 용량 또는 퍼센트가 계속 변하는지 확인한다. 앱에 다시 들어가도 같은 진행 상태가 보이는지 확인한다.
5. 다운로드가 끝나면 SHA-256 무결성 확인과 저장 완료 상태가 나타나는지 확인하고, E2B가 현재 작업 모델로 선택됐는지 확인한다.

> 백그라운드 상태에서 단 한 번의 다운로드만 허용한다. E2B가 진행 중일 때 E4B를 눌러도 새 다운로드 안내나 두 번째 다운로드가 시작되면 안 된다.

## 오프라인 교사 작업 흐름

| 단계 | 조작 | 통과 기준 |
|---|---|---|
| 모델 준비 | 홈의 문항 생성 카드를 누른다. | E2B가 준비되고 문항 생성 입력창이 열린다. |
| 자료 등록 | TXT, 텍스트형 PDF, 비민감 이미지 각 1개를 자료 준비에서 등록한다. | TXT·PDF 내용이 표시되고 PDF는 쪽수 범위도 남는다. 이미지 내용 읽기는 로컬 모델 준비 뒤에만 활성화된다. |
| 비행기 모드 | 모델 준비를 마친 뒤 비행기 모드를 켠다. | 기존 자료와 E2B로 짧은 문항 생성·자동 검수가 응답한다. |
| 검수 | 검수함에서 결과를 열고 교사 검수 후 승인한다. | 승인 상태가 남고 자료 근거를 확인할 수 있다. |
| 문서 공유 | 승인 문항에서 DOCX와 PDF를 각각 공유한다. | Android 공유 시트가 열리고, 선택한 문서 앱에서 파일이 열린다. |

## 성능과 안정성 기록

E2B를 10분 안팎으로 사용하며 체감만 간단히 기록한다. 수치형 진단 도구 설치나 기기 식별 정보 전송은 요구하지 않는다.

| 항목 | 기록 방법 | 판단 기준 |
|---|---|---|
| 응답 시작 체감 | 짧은 문항 생성 요청 1회 | 즉시·보통·느림 중 선택 |
| 발열 | 손으로 느끼는 기기 온도 | 없음·미약·뚜렷함 중 선택 |
| 배터리 | 시작과 종료 퍼센트 | 차이 기록 |
| 앱 안정성 | 사용 중 오류 여부 | 오류 문구와 발생 단계만 기록 |
| 백그라운드 다운로드 | 다른 앱 사용 후 진행 상태 | 계속됨·중단됨 중 선택 |

## E4B 선택 시험

E2B 전체 흐름을 통과한 경우에만 E4B를 선택 시험한다. E4B는 Galaxy S25+에서도 응답이 더 느리거나 발열·배터리 사용량이 늘 수 있으므로, 짧은 생성·검수 요청과 5분 정도의 체감만 기록한다. E4B가 E2B보다 항상 더 좋은 문항을 만든다고 간주하지 않는다.
