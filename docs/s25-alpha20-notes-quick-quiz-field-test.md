# S25+ alpha.21 메모장·쪽지시험·채팅 현장 시험 절차

이 절차는 **EunmaStudio 문제 출제 워크스페이스 0.1.0-alpha.21 Debug APK**의 S25+ 실기기 확인용입니다. APK 파일은 `eunmastudio-teacher-workspace-0.1.0-alpha.21-debug.apk`이며, SHA-256은 `079a21321fce74492951b9d2d66c7af2c85c66bb703c17bd90d50b956a53f449`입니다.

## 사전 조건

| 항목 | 확인 기준 |
|---|---|
| 설치 | 기존 alpha.20 위에 설치하거나, 필요한 경우 기존 앱을 제거한 뒤 alpha.21을 설치한다. |
| 모델 | 모델 관리에서 Gemma 4 E2B를 내려받아 선택한다. E4B는 선택 시험으로만 수행한다. |
| 네트워크 | 모델 설치 뒤 비행기 모드에서도 시험한다. 쪽지시험 생성은 설치된 로컬 모델만 사용한다. |
| 앱 잠금 | 설정에서 앱 잠금을 켠 뒤, 화면 잠금 또는 앱 전환 후 재진입을 시험한다. |

## 메모장 시험

| 순서 | 행동 | 기대 결과 |
|---:|---|---|
| 1 | 홈의 **메모장** 카드를 연다. | 칠판형 전용 화면이 열리며, AI 요청에 자동 반영되지 않는다는 안내가 보인다. |
| 2 | 제목과 본문을 입력하고 `상단에 고정`을 선택해 저장한다. | 저장 메모 목록 최상단에 표시된다. |
| 3 | 메모를 수정한 뒤 저장한다. | 기존 메모가 수정되고 새 메모가 중복 생성되지 않는다. |
| 4 | 새 메모를 추가하고 상단 고정 여부를 다르게 한다. | 고정 메모가 일반 메모보다 위에 정렬된다. |
| 5 | 메모를 삭제하고 앱을 완전히 종료한 뒤 다시 연다. | 삭제 메모는 복원되지 않고, 남은 메모는 기기 안에 유지된다. |

## 간결한 쪽지시험 시험

| 순서 | 행동 | 기대 결과 |
|---:|---|---|
| 1 | 홈의 **간결한 쪽지시험** 카드를 연다. | 과목·단원·개념·난이도·문항 수 입력란과 검수 목록이 보인다. |
| 2 | `화학 I / 화학 결합 / 공유 결합의 정의 / 낮음 / 3`으로 생성한다. | E2B가 준비된 뒤 짧은 개념 확인 문항이 생성되고, 검수 전 목록에 저장된다. |
| 3 | 생성 결과를 연다. | 문항·보기·정답·해설·개념 구분을 확인하고, 긴 배경 설명 또는 복합 자료가 없는지 확인한다. |
| 4 | `교사 검수 후 승인`, `수정 필요`, `보류`를 각각 시험한다. | 선택한 검수 상태가 목록에 즉시 반영되고, 앱 재실행 후에도 유지된다. |
| 5 | 생성 결과를 삭제한다. | 해당 목록 항목만 기기에서 삭제된다. |
