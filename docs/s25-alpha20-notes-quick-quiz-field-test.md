# S25+ alpha.23 메모장·쪽지시험·채팅·고급 설정 현장 시험 절차

이 절차는 **EunmaStudio 문제 출제 워크스페이스 0.1.0-alpha.23 Debug APK**의 S25+ 실기기 확인용입니다. APK 파일은 `eunmastudio-teacher-workspace-0.1.0-alpha.23-debug.apk`이며, SHA-256은 `d95f8254ad56b5918425fd1344d83c2f222527c32f56cc833fdc7960166f5731`입니다.

## 사전 조건

| 항목 | 확인 기준 |
|---|---|
| 설치 | 기존 alpha.22 위에 설치하거나, 필요한 경우 기존 앱을 제거한 뒤 alpha.23을 설치한다. |
| 모델 | 모델 관리에서 Gemma 4 E2B를 내려받아 선택한다. E4B는 선택 시험으로만 수행한다. |
| 네트워크 | 모델 설치 뒤 비행기 모드에서도 시험한다. 쪽지시험 생성은 설치된 로컬 모델만 사용한다. |
| 앱 잠금 | 설정에서 앱 잠금을 켠 뒤, 화면 잠금 또는 앱 전환 후 재진입을 시험한다. |

## 메모장 시험

| 순서 | 행동 | 기대 결과 |
|---:|---|---|
| 1 | 홈의 **메모장** 카드를 연다. | 칠판형 전용 화면이 열리며, AI 요청에 자동 반영되지 않는다는 안내가 보인다. |
| 2 | 제목과 본문을 입력하고 `상단에 고정`을 선택해 저장한다. | 저장 메모 목록 최상단에 표시된다. |

| 4 | 새 메모를 추가하고 상단 고정 여부를 다르게 한다. | 고정 메모가 일반 메모보다 위에 정렬된다. |
| 5 | 메모를 삭제하고 앱을 완전히 종료한 뒤 다시 연다. | 삭제 메모는 복원되지 않고, 남은 메모는 기기 안에 유지된다. |
