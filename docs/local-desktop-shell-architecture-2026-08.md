# 설치형 로컬 앱 아키텍처 기준

**목표:** 교사가 웹앱과 거의 같은 자료 등록·기출 관리·문항 생성·검수·내보내기 흐름을 사용하되, 로컬 모드에서는 자료와 문항을 교사 PC 밖으로 전송하지 않는다.

## 1. 실행 구조

설치형 앱은 Electron 또는 Tauri의 **데스크톱 셸**, loopback 전용 **로컬 브리지**, SQLite 기반 **로컬 저장소**의 세 층으로 분리한다. 셸은 공개 웹 주소를 열지 않고 로컬 UI 자산만 표시한다. 브리지는 `127.0.0.1`에서만 수신하고 단기 세션 토큰을 요구하며, Ollama·llama.cpp도 loopback 주소로만 호출한다.

| 계층 | 책임 | 금지 사항 |
|---|---|---|
| 데스크톱 셸 | 교사용 화면, 파일 선택, 인쇄 미리보기, 운영체제 저장 대화상자 | Node 권한을 렌더러에 직접 노출, 외부 웹 탐색 허용 |
| preload·IPC | 좁은 명령 집합으로 화면과 로컬 기능 연결 | 임의 파일 경로·임의 URL·임의 셸 명령 전달 |
| 로컬 브리지 | 런타임 상태, 모델 목록·다운로드, 로컬 모델 생성 | LAN·공개 IP 수신, 외부 개인 API 호출 |
| SQLite·암호화 폴더 | 자료·기출·문항·근거·검수·출력 이력 | 자동 클라우드 동기화, 평문 API 키 저장 |

Electron은 `BrowserWindow`로 로컬 HTML을 열고, 인쇄용 별도 창에서 `webContents.print()` 또는 `webContents.printToPDF()`를 사용할 수 있다.[1] 초기 구현에서는 교사가 운영체제의 프린터 또는 ‘PDF로 저장’을 직접 선택하는 흐름을 기본값으로 둔다. 무대화상자(silent) 인쇄는 시험 자료의 오발송 위험 때문에 제공하지 않는다.

## 2. 웹·로컬 공통 기능의 출시 순서

| 순서 | 로컬 화면 | 공통 데이터 계약 | 출시 기준 |
|---:|---|---|---|
| 1 | 대시보드·AI 상태·모델 준비 | 로컬 프로필·런타임 상태 | Ollama 설치·사양·모델 상태를 교사 용어로 표시 |
| 2 | 참고 자료·기출 등록 | 자료·기출·원본 위치·선택 상태 | 로컬 파일 선택, 삭제, 원본 PDF 열기, SQLite 저장 |
| 3 | 문항 생성·검수 | 생성 요청·문항·근거·검증·검수 이력 | 로컬 모델 생성과 승인·수정·반려 기록 |
| 4 | 승인 문항·내보내기 | CSV·DOCX·인쇄 HTML | DOCX 저장, 인쇄 미리보기, 교사 선택 PDF 저장 |
| 5 | 설치·복구 | 앱 버전·데이터 위치·백업 안내 | Windows 설치 파일, 안전한 업데이트, 복구 안내 |

## 3. 로컬 전용 보안 기본값

로컬 모드는 Gemini·OpenAI·Claude 등 외부 개인 API를 제공하지 않는다. 자료·프롬프트·문항·정답·해설은 로컬 모델 실행 중 PC 안에서만 처리한다. 처음 모델을 준비하는 다운로드와 교사가 직접 여는 공식 자료 링크만 네트워크를 사용할 수 있으며, 이 경우에도 교사에게 대상과 이유를 표시한다.

| 보안 항목 | 기본값 |
|---|---|
| 렌더러 권한 | `contextIsolation: true`, `nodeIntegration: false` |
| 외부 탐색 | 기본 차단, 공식 자료 링크만 명시적 외부 브라우저 열기 |
| 파일 선택 | 운영체제 파일 선택 대화상자로 한정, 앱 데이터 폴더에 복사 또는 참조 기록 |
| 인쇄·PDF | 교사 명시 실행, 시험지와 정답·해설 분리 |
| 개인 API | 로컬 UI·브리지에서 비노출·차단 |
| 데이터 동기화 | 기본 비활성, CSV·DOCX의 교사 수동 내보내기만 허용 |

## 4. 검증 기준

설치형 앱을 일반 교사에게 배포하기 전에는 아래 항목을 자동·수동으로 모두 확인한다.

1. 렌더러가 임의 셸 명령, 외부 URL, 임의 로컬 경로에 접근할 수 없어야 한다.
2. 로컬 모델 생성 요청이 loopback 이외의 주소로 전송되지 않아야 한다.
3. 자료·기출·문항·검수 이력과 CSV·DOCX 출력이 웹 계약의 필수 필드를 보존해야 한다.
4. 시험지와 정답·해설지가 별도로 출력되고, 인쇄·PDF 저장 전에 보안 안내가 보여야 한다.
5. 모델 미설치·저성능·생성 실패 시 외부 API로 자동 전환하지 않고 수동 검수 또는 다른 로컬 모델을 제안해야 한다.
