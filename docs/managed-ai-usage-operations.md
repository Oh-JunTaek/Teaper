# 개발·파일럿 관리형 AI 사용량 운영 기준

## 목적과 범위

이 기능은 EunmaStudio 교사도우미의 **개발·파일럿 기간**에 관리형 AI 호출 규모와 제한 응답을 점검하기 위한 운영 도구다. 개인 Gemini·OpenAI·Claude API와 로컬 AI 호출은 이 집계 대상이 아니다. 관리형 AI로 수행한 문항 생성, 답·해설 검증, 이미지·스캔 자료 내용 추출만 날짜별 합계로 기록한다.

## 저장하는 값과 저장하지 않는 값

| 저장하는 일별 합계 차원 | 저장하지 않는 값 |
|---|---|
| 날짜, 작업 유형, 성공·실패·제한 결과, 모델명, 처리 시간 구간, 호출 수 | 사용자 ID·이름·이메일, IP·기기·쿠키, 프롬프트·문항·정답·해설, 자료 본문·파일명·URL, 개인 API 키, 정확한 호출 시각 |

이 설계에서는 개인별 사용량이나 고유 사용자 수를 계산하지 않는다. 관리자 화면도 개인 식별 정보가 없는 최근 14일 합계·일별 집계 행만 보여 준다.

## 운영 절차

관리자는 `운영 도구 → 개발용 관리형 AI 사용량`에서 호출 합계, 성공, 실패, 제한 응답을 확인한다. 제한 응답이 늘어나면 새 파일럿 참여자에게 개인 API 또는 로컬 AI 선택을 안내하고, 개발 테스트를 줄이거나 관리형 AI 기본값을 임시 비활성화한다. 실패 기록은 오류 원문이 아니라 결과 분류만 남기므로, 원인 분석은 별도의 서버 보안 로그 접근 권한과 최소 열람 원칙에 따라 수행한다.

## 보존과 정식 배포 전환

일별 집계 보존 원칙은 90일이다. 현재는 개발·파일럿 점검을 위한 집계·조회만 구현되어 있으며, 정식 공개 전에는 승인된 삭제 또는 월별 축약 절차를 별도 구현해야 한다. 정식 서비스에서 관리형 AI를 제공하지 않기로 결정하면, 관리형 AI 선택지를 숨기고 개인 API·로컬 AI만 허용한 뒤 이 집계 기능도 비활성 또는 삭제 대상으로 검토한다.
