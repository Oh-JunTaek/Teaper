# 교사용 로컬 AI 준비 안내

## 권장 방식: Ollama 설치 파일

비개발자 교사에게는 **Ollama 설치 파일 방식**을 기본 경로로 권장한다. Windows에서 `OllamaSetup.exe`는 관리자 권한 없이 계정별 설치가 가능하고, 로컬 API는 `localhost:11434`에서 동작한다. [1] 명령 프롬프트·PowerShell 명령은 설치 파일 방식이 실패하거나 운영자가 원격 지원할 때만 고급 경로로 안내한다.

| 선택지 | 권장 대상 | 교사 기본 경로 여부 |
|---|---|---|
| Ollama 설치 파일 | Windows 교사 개인 PC, 모델을 간단히 내려받아 실행하려는 경우 | **기본** |
| Ollama 명령줄/PowerShell | 설치 자동화·고급 문제 해결이 필요한 경우 | 고급 지원 전용 |
| llama.cpp | 특정 GGUF 모델, 특수 하드웨어·성능 튜닝이 필요한 경우 | 운영자·고급 사용자 전용 |

llama.cpp는 다양한 하드웨어와 양자화를 폭넓게 지원하지만, 사전 빌드·모델 파일·서버 실행을 교사가 직접 관리해야 할 수 있으므로 초기 파일럿의 기본 경로로는 적합하지 않다. [2]

## 준비 순서

1. 교사도우미 로컬 앱에서 **내 PC 확인**을 누른다.
2. 앱이 메모리·GPU·여유 공간을 읽고 경량/표준/권장 모델을 제시한다.
3. **Ollama 내려받기**를 누르면 공식 다운로드 페이지가 열린다. 설치 파일을 실행한다.
4. 앱으로 돌아와 **설치 확인**을 누른다. Ollama 실행과 설치된 모델 목록을 확인한다.
5. 모델 이름·대략적 저장공간·라이선스 확인 화면을 본 뒤 **이 모델 준비하기**를 누른다.
6. 다운로드가 끝나면 짧은 문항 생성 점검을 실행한다. 이후 자료·문항·근거는 PC 내부에서 처리한다.

## 사양별 시작 모델

| PC 상태 | 시작 모델 | 기대 범위 |
|---|---|---|
| 메모리 8GB 이상, GPU 없음 또는 저사양 | `qwen3:4b` | 가벼운 개념 확인·자료형 문항부터 시작 |
| 메모리 16GB 이상 또는 VRAM 6GB 이상 | `qwen3:8b` | 일반 화학 I 생성·근거 정리에 균형 |
| 메모리 32GB 이상 또는 VRAM 10GB 이상 | `qwen3:14b` | 복잡한 근거 종합·해설 품질 우선 |

위 모델은 앱의 시작 추천값일 뿐, 교사 검수 없이 시험문제로 사용해서는 안 된다. 모델 파일은 수 GB 이상일 수 있고, Ollama는 모델 저장 위치를 `OLLAMA_MODELS` 환경 변수로 변경할 수 있다. [1]

## 로컬 전용 안전 원칙

로컬 전용 모드에서는 자료 원문, 문항, 임베딩, API 키가 교사 PC 밖으로 전송되지 않는다. 다만 **모델을 처음 내려받을 때만 인터넷 연결이 필요**하다. 모델 제공자의 라이선스·상업 이용 조건·재배포 조건은 모델마다 다를 수 있으므로, 앱은 내려받기 전 모델명과 라이선스 확인 단계를 표시해야 한다.

## 문제 해결

| 증상 | 먼저 할 일 |
|---|---|
| 설치 확인 실패 | Ollama를 설치한 뒤 앱을 다시 열고, PC를 재시작한 후 다시 확인 |
| 모델 다운로드 실패 | 저장공간·인터넷 연결을 확인하고, 모델 저장 드라이브 위치를 변경 |
| 생성이 매우 느림 | 한 단계 작은 모델로 바꾸거나 다른 작업을 닫고 재시도 |
| 결과 품질이 낮음 | 근거 자료·출제 지침을 보강하고, 표준 모델 또는 관리형 AI를 선택 |
| 자료를 외부로 보내고 싶지 않음 | 개인 외부 API를 선택하지 말고 로컬 전용 모드만 사용 |
