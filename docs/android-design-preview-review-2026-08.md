# Android 카드형 디자인 미리보기 검토 기록

## 검토 대상

| 화면 | 파일 | 검토 목적 |
|---|---|---|
| 홈 | `eunmastudio-android-home-design-preview.png` | 교사 작업 카드와 모델 관리 진입점의 시각 계층 확인 |
| 모델 관리 | `eunmastudio-android-model-manager-design-preview.png` | E2B 기본·E4B 고성능 권장·진행 상태·라이선스 안내의 계층 확인 |

## 확인 결과

| 항목 | 결과 | 실제 앱 반영 상태 |
|---|---|---|
| 어두운 그래파이트 배경과 높은 대비 | 통과 | `MainActivity`와 `ModelManagerActivity`에 반영 |
| 홈의 모델 관리 카드 | 통과 | 홈 상단 진입 카드로 반영 |
| 자료 준비·문항 생성·검수함·교사 작성 선호 카드 | 통과 | 4개 카드형 작업 진입점으로 반영 |
| E2B 파란 기본 강조 | 통과 | 기본 모델 카드와 선택 상태에 반영 |
| E4B 금색 고성능 강조 | 통과 | E4B 카드 및 발열·배터리 안내에 반영 |
| 진행 용량·퍼센트·속도 | 통과 | 포그라운드 다운로드 서비스 상태와 반영 |
| 라이선스·NOTICE 진입점 | 통과 | 모델 관리 화면 하단에 반영 |

## 주의 사항

이 이미지는 카드 계층과 색상 방향을 확인하기 위한 **시각 미리보기**이며, 실제 Android 화면 캡처는 아니다. 현재 개발 환경은 하드웨어 가속 가상화를 사용할 수 없어 Android 에뮬레이터가 부팅 완료 상태까지 도달하지 못했다. 실제 Android 렌더링·문구·여백·알림 표시는 Galaxy S25+에서 alpha.3을 실행해 별도로 대조한다.
