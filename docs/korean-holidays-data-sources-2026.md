# 2026년 일정 달력 공휴일 기본값

## 적용 원칙

웹·Windows·Android 일정 달력은 **2026년 대한민국 공휴일·대체공휴일의 기본 표시값을 앱에 포함**한다. 달력을 열 때 외부 API를 호출하지 않으므로 교사 일정·자료·문항 정보가 외부로 전송되지 않는다. 공휴일 보기는 표시 전용이며, 일정 추가·알림·AI 요청에 공휴일 정보를 자동 전송하지 않는다.

2026년의 고정·음력·대체공휴일·선거일 기본값은 아래 자료를 대조해 반영했다. 법령 개정, 임시공휴일 지정, 선거일 변동이 생길 수 있으므로 다음 배포 전에 해당 연도의 공휴일을 재검토해야 한다.

| 자료 | 사용 목적 | URL |
|---|---|---|
| `holidays-kr` 2026 JSON | 날짜·명칭·대체공휴일의 로컬 기본값 대조 | https://holidays.hyunbin.page/2026.json |
| `holidays-kr` 프로젝트 안내 | 월력요항 기반 생성·데이터 형식·공공 API 키 제약 확인 | https://github.com/hyunbinseo/holidays-kr |
| 국가법령정보센터 | 공휴일 및 대체공휴일 제도 변경 검토 | https://www.law.go.kr |

## 운영 확인표

1. 연도 변경 전에는 월력요항 또는 공공데이터포털의 특일 정보를 확인한다.
2. 임시공휴일·선거일은 공고 뒤 해당 연도의 로컬 기본값에 추가한다.
3. 웹·Windows·Android의 같은 날짜와 표기를 대조한다.
4. 공휴일 이름·날짜를 AI 요청, 운영 통계, 외부 캘린더에 자동 전송하지 않는다.
