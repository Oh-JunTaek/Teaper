# 교사용 문서·PDF 내보내기 정책

**기준일:** 2026-08-21  
**적용 범위:** EunmaStudio 문제 출제 워크스페이스 웹앱 및 로컬 번들

## 1. 제공 형식과 사용 목적

승인된 문항은 단순 목록 관리용 CSV 외에, 교사가 바로 편집·인쇄할 수 있는 **시험지 DOCX** 및 **정답·해설지 DOCX**로 제공한다. PDF는 별도 인쇄 미리보기에서 교사가 자신의 프린터 또는 ‘PDF로 저장’을 선택해 생성한다. 시험지와 정답·해설지는 의도치 않은 정답 유출을 막기 위해 별도 파일로 나눈다.

| 형식 | 용도 | 포함 내용 | 현재 지원 |
|---|---|---|---|
| DOCX 시험지 | Word·한글 편집, 시험지 구성 | 문항·보기·배점·그래프·표 | 웹·로컬 출력 기반 구현 |
| DOCX 정답·해설지 | 교사용 검토·채점 준비 | 문항·정답·해설·출제 의도·그래프·표 | 웹·로컬 출력 기반 구현 |
| 인쇄용 PDF | 배포 전 최종 인쇄 확인 | 시험지 또는 정답·해설지 | 웹은 브라우저 인쇄 흐름, 로컬 설치형 UI 연결 예정 |
| CSV | 문항 은행 정리·스프레드시트 분석 | 문항 정보 중심 목록 | 웹·로컬 지원 |

## 2. 한글 문서 호환 원칙

DOCX는 Office Open XML 표준에 기반한 편집 가능한 문서 형식이며, 한컴오피스도 OOXML의 불러오기·저장 기능을 지원한다.[1] [2] 초기 서비스는 DOCX를 기본 편집 문서로 삼고, 한글 사용자는 파일을 연 후 HWPX로 저장하는 경로를 안내한다.

HWPX·OWPML 관련 형식 정보는 공개되어 있으나, 직접 HWPX를 생성하려면 표·수식·그래프·스타일·버전별 호환성을 별도로 검증해야 한다.[3] 따라서 초기에는 구형 HWP 또는 HWPX를 직접 생성한다고 약속하지 않는다. DOCX를 한글에서 연 뒤 HWPX로 저장하는 방법이 교사 사용성과 기술 위험 사이에서 더 안정적이다.

> 그래프·표·수식이 있는 문항은 내보낸 뒤 실제 사용하는 Word 또는 한글 버전에서 반드시 최종 모양을 확인해야 합니다. 생성 파일은 교사의 최종 검수와 학교 시험 규정을 대체하지 않습니다.

## 3. 시험 보안 출력 원칙

내보내기 시작 전에는 문항·정답·해설이 민감한 시험 자료일 수 있음을 알린다. 웹앱은 사용자가 명시적으로 내보내기 형식을 선택한 경우에만 파일을 생성하며, 로컬 번들은 교사가 선택한 로컬 경로에만 저장한다. 서비스는 외부 메일·클라우드·메신저로 자동 전송하지 않는다.

| 통제 항목 | 원칙 |
|---|---|
| 시험지·정답 분리 | 시험지와 정답·해설지는 항상 별도 출력 |
| 출력 전 안내 | 보안 저장 위치·출력 장치·최종 검수 경고를 표시 |
| 자동 외부 전송 | 제공하지 않음 |
| 원본 대조 | PDF·그래프·표·수식은 교사가 파일을 열어 최종 확인 |
| 실행 이력 | 향후 기관 모드에서 내보내기 감사 이력·권한·보존기간을 추가 검토 |
