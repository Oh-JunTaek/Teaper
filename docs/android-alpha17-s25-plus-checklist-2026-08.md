# Android alpha.17 · S25+ 작업 흐름 및 UI 확인

## 설치 확인

- 앱 정보에서 `0.1.0-alpha.17`인지 확인한다.
- 설치 전 실행 중인 앱을 완전히 종료하고 alpha.16 위에 업데이트한다.

## 문항 생성

1. 홈의 **문항 생성** 카드를 탭한다.
2. 모델 준비 여부와 무관하게 요청 입력 팝업이 즉시 보이는지 확인한다.
3. 요청을 입력하고 **생성 시작**을 선택한다.
4. E2B가 설치된 경우 CPU 안정성 모드 준비 뒤 문항 생성 결과가 검수함에 저장되는지 확인한다.

## 자료 준비

1. 홈의 **자료 준비** 카드를 탭한다.
2. 최상위 목록에 `파일에서 참고 자료 추가` 같은 중복 버튼 없이 **자료 추가**와 **공식 자료 찾아보기**가 있는지 확인한다.
3. **자료 추가** 안에서 자료 구분을 고르고 **직접 작성** 또는 **파일 업로드**를 선택할 수 있는지 확인한다.
4. **공식 자료 찾아보기**에서 국가교육과정정보센터·교육부·한국교육과정평가원 버튼을 누르면 브라우저가 열리는지 확인한다.

## 시각·대화상자

1. 홈 카드와 채팅 배경이 어두운 녹색 칠판 계열이며, 텍스트 대비가 충분한지 확인한다.
2. 자료 준비·문항 생성·검수함 팝업이 기본 회색 시스템 알림창 대신 둥근 모서리·분필 테두리·금색 주요 버튼의 서비스 팝업으로 보이는지 확인한다.
3. AI 채팅 카드가 다른 작업 카드와 같은 2열 카드 비중을 유지하는지 확인한다.

화면이 잘리거나 카드 탭이 반응하지 않으면 앱 버전·탭한 카드·화면 캡처를 함께 기록한다.
