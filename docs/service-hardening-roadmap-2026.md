# 문제 출제 워크스페이스 강화 로드맵

**작성:** EunmaStudio  
**기준:** 2026년 8월 파일럿  
**목표:** 교사가 자료를 확인하며 문항을 만들고 최종 검수하는 서비스의 신뢰성·보안성·확장성을 단계적으로 강화한다.

> **핵심 판단:** 서비스의 경쟁력은 문항을 많이 생성하는 데 있지 않다. **공식 기준 → 학교 자료 → 문항 → 검수 → 수정 이력**이 끊기지 않는 ‘출제 근거 체계’를 만들고, 수학·보안·운영 위험을 자동화가 아닌 안전장치로 관리하는 데 있다.

## 1. 공통 공식 자료: 과목 자료보다 먼저 갖춰야 할 기반

현재 과목별 교육과정 링크는 준비되었지만, 모든 과목에 공통 적용할 수 있는 ‘출제 규칙 자료’가 부족하다. 아래 다섯 층을 기본 카탈로그로 분리하는 것을 권고한다.

| 자료 층 | 공통 공식 자료 | 서비스에서의 역할 | 사용 원칙 |
|---|---|---|---|
| A. 교육과정 운영 | 2022 개정 교육과정 총론 | 학교급·학년 적용 시기, 학교 교육과정 편성, 공통 운영 기준 확인 | 모든 과목의 상위 기준으로 연결 |
| B. 교과 범위 | 과목별 교육과정·과학계열 선택 과목 교육과정 | 성취기준·내용 체계·과목 경계 확인 | 학교급·교과·과목 선택 후 노출 |
| C. 평가 기준 | 성취기준·성취수준(평가기준) | 문항의 성취기준 매핑, 평가 요소와 기대 수준 확인 | 문항마다 최소 1개 연결을 목표 |
| D. 평가 도구 | KICE 수행평가·서논술형·현장중심 학생평가 자료 | 문항정보표, 채점기준, 서술형·수행평가 설계 보조 | 원문 복제 대신 공식 링크·메타데이터 제공 |
| E. 학교 맥락 | 교사의 평가계획·수업 자료·학기 운영표 | 실제 시험 범위, 배점, 학교별 출제 유의사항 반영 | 교사별 격리·삭제·원본 위치 기록 |

교육부 고시 제2022-33호는 총론, 수학과·과학과 교육과정, 과학계열 선택 과목 교육과정을 함께 고시했고, 2025~2027년에 중·고등학교 학년별로 순차 적용하도록 정한다.[1] KICE 학생평가지원포털은 성취기준(평가기준) 검색 및 수행평가·서논술형·현장중심 학생평가 도구를 제공한다.[2]

|---:|---|---|---|---|

| P1 | 운영 장애·복구 | 정책·사용량 조회·소유권 제어 구현 | 백업·복구 훈련, 장애 등급·알림, 변경 이력 승인 절차 | 복구 절차를 운영자가 정기 검증 |
| P2 | 기관 확장 | 역할 기반 서버 경계와 정책 초안 보유 | 기관·교사·검토자 역할, 기관별 보존기간·감사 이력 | 별도 기관 테넌트에서 자료·문항 완전 분리 |

## 3. 단계별 강화 로드맵

### 1단계: 다음 파일럿 전 — ‘틀리지 않고, 새지 않게’

가장 먼저 공통 공식 자료 카탈로그에 **교육과정 총론**, **KICE 성취기준·평가기준 검색**, **KICE 평가도구**를 링크 전용으로 추가한다. 이후 문항에 성취기준·평가기준 연결 상태를 표시하고, 중등 수학의 수치 계산부터 계산 대조 기능을 도입한다. 게스트는 관리형 AI 생성 횟수를 제한하고, 개인 API 또는 로컬 AI 전환을 우선 안내한다.

### 2단계: 과목 확장 전 — ‘검수 가능한 품질 체계’

과목별로 교사 검수 완료 문항 30~50개 정도의 비공개 테스트 묶음을 만든다. 이 자료는 모델 학습용이 아니라, 새 모델·프롬프트·계산 검증 로직을 바꿀 때 정답, 조건, 난이도, 출처 표기가 유지되는지 확인하는 회귀 테스트 기준으로 쓴다. 과목 공개는 **공식 문서 준비 → 대표 단원 검수 → 테스트 묶음 통과 → 제한 공개** 순으로 한다.

### 3단계: 정식 공개·기관 도입 — ‘운영 가능한 제품’

개별 초대 링크·역할·자료 보존기간·감사 이력·비상 대응 절차를 기관 단위로 구성한다. 관리형 AI는 기본값이 아니라 시범 기능으로 두고, 기관 정책에 따라 개인 API, 기관 계약 API, 로컬 AI 중 하나를 선택하도록 한다. 공개 후에는 문항 수보다 **승인률, 수정 이유, 계산 불일치율, 근거 확인 소요 시간**을 익명 집계로 확인한다.
