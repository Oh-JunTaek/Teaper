# Android alpha.19 빌드 검증 기록

## 구현 범위

대화 목록에서 메시지 미리보기를 제거하고 제목·상대 시간만 표시한다. **관리** 버튼은 카드 우측에 독립 배치되며 제목 변경, 즐겨찾기, 삭제를 제공한다. 즐겨찾기한 대화는 일반 대화보다 먼저 정렬하고, 여러 즐겨찾기 가운데 가장 최근에 지정한 대화가 최상단에 온다.

대화 원문은 현재 플랫폼별 저장 경계를 유지한다. 웹·Windows·Android 사이의 자동 동기화는 교사 명시 동의, 기기별 암호화 키, 동기화 범위, 삭제·충돌 처리 정책이 확정되기 전까지 구현하지 않는다. 공통 기능·모바일 전용 기능의 판정 및 후속 적용은 `cross-platform-feature-contract-2026-08.md`에 기록한다.

## 검증 결과

`testDebugUnitTest`와 `assembleDebug`는 `BUILD SUCCESSFUL`로 완료되었다. 상대 시간 및 즐겨찾기 정렬의 정책 회귀 테스트를 추가했다. 설치 APK는 `versionCode=19`, `versionName=0.1.0-alpha.19`이며 SHA-256은 `be3d815190e2039f96e75611ef18897cda436c9d367afa660ef073243aba9be9`이다.
