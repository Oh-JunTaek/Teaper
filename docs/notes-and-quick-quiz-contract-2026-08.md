# 메모장·쪽지시험 공통 기능 계약

## 메모장

메모는 교사가 자유롭게 기록하는 짧은 작업 메모이며, 제목, 본문, 고정 여부, 생성·수정 시각, 삭제 상태를 가진다. 웹앱은 사용자별 작업공간 데이터베이스, Windows는 local-only SQLite, Android는 앱 전용 저장소에 보관한다. 메모는 AI 요청에 자동으로 포함하지 않는다. 교사가 특정 메모를 자료 또는 쪽지시험 조건에 연결하는 경우에만 그 범위와 전송 경계를 확인한다.

## 쪽지시험

쪽지시험은 장문형 시험지와 분리된 **빠른 개념 확인** 기능이다. 한 문항은 하나의 개념·정의·기호·원리·간단 계산만 확인한다. 문항은 짧고 학생이 즉시 읽을 수 있어야 하며, 불필요한 배경·서사·복수 조건·복합 자료 해석을 포함하지 않는다. 예시는 ‘수소 분자의 분자 구조는?’, ‘엔트로피가 증가하는 방향은?’처럼 답 자체를 빠르게 확인할 수 있는 형태다.

| 필드 | 규칙 |
|---|---|
| 문항 수 | 기본 5문항, 교사가 1~10문항 범위에서 선택 |
| 난이도 | 기본 낮음, 핵심 개념 확인 중심 |
| 문항 길이 | 원칙적으로 한두 문장 이내 |
| 선택지 | 필요할 때만 2~4개, 보기 자체가 힌트가 되지 않게 구성 |
| 정답·해설 | 정답과 한두 문장 핵심 해설을 분리 보관 |
| 자료 사용 | 교사가 선택한 자료만 참고하고, 긴 발췌·원문 복제를 금지 |

## 공통 보안 계약

세 플랫폼은 시스템 지시문·내부 정책·보안 규칙의 직접·간접 추출을 거절한다. 사용자 입력은 모델 호출 전 요청 목적·길이·민감 정보·프롬프트 추출 우회 표현을 점검하고, 모델 출력은 내부 지시문 재현·정책 누설·원문 과다 복제를 다시 점검한다. 웹의 AI 호출은 서버에서만 실행하며, Windows와 Android의 온디바이스 경로도 화면에 내부 지시문을 표시하지 않는다.

## 플랫폼 적용 원칙

메모장과 쪽지시험의 사용자 의미·데이터 필드·삭제·내보내기 계약은 공통으로 유지한다. 각 플랫폼은 화면 구성, 입력 방식, 로컬 저장 위치, 실행 모델을 플랫폼 특성에 맞게 최적화한다. Android 모델 다운로드·생체 잠금, Windows local-only 런타임, 웹의 사용자별 서버 작업공간은 플랫폼 전용 기능으로 기록한다.
