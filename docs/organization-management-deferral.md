# 기관 사용자 관리 기능 보류 결정

## 현재 결정

교사 개인 중심 파일럿에서는 다른 사용자 계정을 관리할 업무가 거의 없고, 사용자 목록 자체가 불필요한 개인정보 노출 면적을 늘린다. 따라서 **사용자 역할·목록 관리 UI는 현재 비노출**로 둔다. 공식 출처·정책 관리가 필요한 운영 기능은 `운영 도구`로 유지한다.

## 보류 범위

| 항목 | 개인 교사 파일럿 | 기관 도입 이후 |
|---|---|---|
| 사용자 목록·역할 변경 | 화면 비노출 | 기관 관리자에게만 재활성화 |
| 이메일·로그인 기록 | 화면/API 표시 금지 | 계약·권한 모델 검토 후 최소 범위 표시 |
| 공식 출처 관리 | 서비스 운영자만 사용 | 기관 관리자 위임 여부 검토 |
| 역할 감사 기록 | 정책 설계만 | 승인 절차·감사 이력과 함께 구현 |

## 재활성화 조건

기관 계약, 관리자 책임자 지정, 역할 변경 승인 절차, 개인정보 처리방침·보존기간·감사 기록이 모두 준비된 경우에만 `ORGANIZATION_MANAGEMENT_ENABLED`를 활성화한다.
