# 중·고등 과학·수학 확장 및 수학 문항 안전장치 권고안

> **핵심 결론:** 중등 과학·수학과 고등 과학·수학의 두 축으로 시작하는 것은 적절하다. 다만 어떤 AI 모델도 수학 문항을 **오류 없이** 푼다고 전제하면 안 된다. 서비스는 수학 문항을 ‘자동 확정’하지 않고, 계산 검증·독립 재검토·교사 최종 승인이라는 세 겹의 안전장치를 제공해야 한다.

## 1. 두 축의 공개 범위

| 축 | 1차 공개 과목 | 후속 과목 | 운영 원칙 |
|---|---|---|---|
| 중등 과학·수학 | 중학교 과학, 중학교 수학 | 기술·정보 연계 단원 | 학년·학기·과목·단원으로 범위를 고정한다. |
| 고등 과학·수학 | 통합과학, 통합과학 탐구, 공통수학1·2 | 물리학·화학·생명과학·지구과학, 대수·미적분Ⅰ·확률과 통계 | 공통 과목을 먼저 공개하고, 선택 과목은 학교 개설 여부·과목 성격을 함께 기록한다. |

고등 과학과 수학의 세부 과목을 한 번에 모두 공개하지 않는 이유는 모델 성능보다 **공식 문서 준비와 검수 책임** 때문이다. 과목마다 성취기준·학교 편성·문항 형식·교사 자료가 다르므로, 한 과목씩 공식 자료와 대표 문항 검수를 통과시킨 뒤 카탈로그에 추가해야 한다.

## 2. 수학 모델 신뢰도에 대한 판단

최신 모델은 특정 산술 벤치마크에서 매우 높은 정확도를 보일 수 있다. 그러나 교육용 수학 문항에는 계산 외에도 조건 해석, 단위·정의역 확인, 복수 해 판별, 보기 구성, 난이도 조절, 해설의 논리적 완결성이 함께 요구된다. 한 연구는 추론 강화 모델의 정확도가 높아져도 절차상 실수가 빈번하며, 이중 에이전트 구성이 정확도를 높인다고 보고했다.[1] 반면 다른 연구의 211개 산술 문제 평가에서는 일부 모델이 제한된 연산 범위에서 100% 정확도를 보였다고 보고했다.[2]

두 결과는 모순이 아니라 적용 범위가 다르다. **단순 산술 정확도**와 **실제 평가 문항 전체의 무오류성**은 같은 기준이 아니다. OpenAI도 연구 수준 수학 증명에서 모델의 일부 풀이가 전문가 검토 후 오류로 판명되었음을 공개하며, 정답성 검토의 필요성을 설명한다.[3]

| 문항 작업 | AI 활용 권고 | 자동 통과 가능 여부 |
|---|---|---|
| 단순 정수·유리수 연산 | 생성 보조 + 계산 엔진 대조 | 계산 엔진 일치 시 후보 통과 |
| 방정식·부등식·함수 | 생성 보조 + 해 집합·정의역 대조 | 교사 검수 필수 |
| 도형·증명·경우의 수 | 발문·해설 초안 보조 | 교사 검수 필수 |
| 자료 분석·통계 | 표·그래프 생성 보조 + 재계산 | 원자료·계산 결과 대조 후 검수 |
| 서술형·논증형 | 평가 요소·채점 기준 초안 보조 | 교사 최종 판단 필수 |

## 3. 지금 서비스의 상태

현재 교사도우미는 문항 생성 뒤 독립 AI 호출로 범위, 정답·해설 일치, 난이도, 지침, 유사도를 재검토한다. 이는 **교차 검토**로 유효하지만, 두 번 모두 AI 판단에 의존한다. 현재에는 다항식 전개, 방정식 해 집합, 행렬·통계 재계산 같은 **결정론적 수학 검증기**가 연결되어 있지 않다.

따라서 현재 상태로는 수학 문항을 생성·검수함에 보내는 범위까지는 가능하지만, ‘검증 통과 = 수학적으로 확정’으로 표시해서는 안 된다.

## 4. 수학 확장 전 필수 안전장치

| 우선순위 | 안전장치 | 작동 방식 | 공개 기준 |
|---:|---|---|---|
| P0 | 수식·조건 구조화 | 문항에서 식, 변수, 정의역, 조건, 정답 형태를 별도 필드로 저장 | 수학 생성 요청부터 적용 |
| P0 | 계산 엔진 대조 | 허용된 수치·대수 유형은 서버 측 계산 라이브러리로 재계산 | 결과 불일치 시 자동 보류 |
| P0 | 수학 검수 상태 | ‘계산 대조 통과/불일치/대상 아님/교사 확인 필요’를 표시 | 승인 전 항상 확인 |
| P1 | 독립 모델 재검토 | 생성 모델과 다른 제공자 또는 다른 모델로 조건·보기·해설 검사 | 개인 API 선택 시 비용·전송 동의 유지 |
| P1 | 반례 탐색 | 보기와 해설에 대해 경계값·특수값을 넣어 모순 탐색 | 함수·부등식·확률 문항 우선 |
| P2 | 과목별 테스트 묶음 | 실제 교사 검수 완료 문항으로 회귀 테스트 | 과목 공개 전 최소 단원별 테스트 통과 |

> **교사 경험 원칙:** 화면에는 ‘AI 수학 검증’ 같은 과도한 기술 용어 대신 **계산 확인**, **조건 확인**, **교사 확인 필요**로 표시한다.

## 5. 권장 구현 순서

첫 구현은 범용 과목 선택 구조와 수학 안전장치의 최소 버전을 함께 만드는 것이다. 실제 공개 과목은 중등 과학·수학, 고등 통합과학·공통수학으로 제한한다. 다음 단계에서 중등 수학의 수치 계산·일차방정식·비례·자료 분석부터 계산 엔진 대조를 붙이고, 고등 수학은 대수·확률과 통계·미적분 순으로 넓힌다. 기하와 증명은 자동 계산 범위가 좁으므로 교사 확인 중심으로 시작해야 한다.
