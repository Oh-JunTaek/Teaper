# 개인정보 최소 사용 통계 계약

**적용 범위:** EunmaStudio 교사도우미 웹, Windows local-only, Android 온디바이스 앱  
**목적:** 교사가 자신의 작업 흐름을 돌아보고, 운영자가 서비스 품질과 안정성을 개선하되 자료·문항·대화의 기밀성을 보존한다.

> 이 계약에서 통계는 **내용이 아닌 수량·성공 여부·시간 구간**만 다룹니다. 교사의 자료 원문, 문항 원문, 정답·해설, 대화, 파일명, 이미지, IP, 기기 식별자, 학생·교사 식별 정보는 운영 통계 값으로 저장하지 않습니다.

| 플랫폼 | 교사에게 보여 주는 개인 작업 현황 | 운영자가 확인하는 최소 집계 | 외부 전송 원칙 |
|---|---|---|---|
| 웹 | 자료·생성 문항·승인 문항·메모·쪽지시험 수, 월간 관리형 AI 성공 작업 수 | 날짜·작업 종류·성공/실패/한도·모델·응답 시간 구간별 합계 | 관리형 AI 운영에 필요한 서버 집계만 사용하며, 프롬프트·원문은 포함하지 않음 |
| Windows local-only | 이 PC의 자료·기출·문항·승인·메모·쪽지시험 수 | 기본 수집 없음 | 자동 외부 전송 금지. 향후 선택 전송은 별도 동의·전송 미리보기·보존 정책·보안 검토 후만 가능 |
| Android 온디바이스 | 이 기기의 자료·문항·승인·메모·쪽지시험·대화 수 | 기본 수집 없음 | 자동 외부 전송 금지. 온디바이스 모델·이미지·대화 내용은 통계 전송 대상이 아님 |

## 개인 작업 피드백

개인 화면은 교사가 서비스 사용 흐름을 점검하기 위한 기능입니다. 숫자는 각 계정 또는 기기의 현재 저장 상태에서 계산하며, 다른 교사와 비교하거나 성과를 평가하는 용도로 사용하지 않습니다. 생성 문항은 검수·승인 여부를 함께 보여 주되, 생성 품질을 자동으로 보장하지 않습니다.

## 운영 통계의 허용 범위

웹의 운영 집계는 관리형 AI 비용·오류·한도·응답 시간 경향을 파악하기 위한 서버 내부 합계입니다. 날짜, 작업 유형, 결과, 모델, 시간 구간, 호출 수, 알려진 토큰 수만 허용합니다. 개별 교사별 월간 포함량 카운터는 플랜 한도를 관리하기 위한 별도 데이터이며, 운영 보고서에서 개인별 목록으로 노출하지 않습니다.

Windows와 Android는 local-only 원칙상 **현재 운영자에게 자동 통계를 보내지 않습니다.** 이 설계는 기능 부족이 아니라 시험 자료와 교사 메모의 외부 이동을 막기 위한 기본값입니다. 추후 사용자가 명시적으로 선택한 경우에만, 기기·계정 식별자 없이 하루 단위로 합쳐진 앱 버전·작업 종류·성공/실패 수를 전송하는 방안을 별도 출시 항목으로 검토합니다. 이 경우에도 전송 전 화면에서 항목·목적·보존 기간·철회 방법을 보여 주고 기본값은 꺼 둡니다.

## 보존·접근 원칙

웹 운영 집계는 서비스 운영에 필요한 기간만 보존하고, 월간 추세 보고서는 더 큰 단위의 합계로 제한합니다. 운영 도구는 관리자 역할로만 접근하며, 개인 작업 화면은 해당 사용자만 볼 수 있습니다. 로컬 앱의 개인 작업 현황은 앱·PC 안에만 남고, 앱 삭제·로컬 데이터 삭제·암호화 백업 복구 흐름을 따릅니다.

## 출시 전 확인 사항

실제 원격 통계 전송을 추가하기 전에는 개인정보 처리방침, 앱 스토어 Data safety 고지, 수집·전송 동의 문구, 보존 기간, 철회·삭제 경로, 운영 접근 권한을 서비스 운영 조건과 함께 재검토합니다. 이 문서는 구현 기준이며 법률 자문이나 최종 고지를 대체하지 않습니다.
