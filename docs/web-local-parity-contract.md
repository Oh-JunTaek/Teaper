# 웹·로컬 서비스 동등성 계약

## 제품 원칙

교사에게 보이는 제품은 하나의 **교사도우미**다. 웹과 로컬은 화면 구성, 교육 현장 용어, 자료 등록, 기출 등록, 문항 생성, 근거 확인, 검수, 승인, 내보내기의 흐름을 동일하게 유지한다. 차이는 AI가 실행되는 위치와 자료가 보관되는 위치뿐이다.

| 영역 | 웹 서비스 | 로컬 서비스 | 교사 화면 원칙 |
|---|---|---|---|
| 로그인·작업공간 | 웹 계정·서버 데이터 | 로컬 프로필·SQLite | 대시보드와 메뉴 순서 동일 |
| 참고 자료 | S3 원본·서버 검색 | PC 원본·SQLite 검색 | 같은 등록·삭제·원본 대조 화면 |
| 기출문제 | 개인 작업공간·S3 PDF | 개인 작업공간·로컬 PDF | 같은 출처·페이지·문항 번호 입력 |
| AI 제공자 | 관리형 AI·개인 API·로컬 bridge 설정 | Ollama·llama.cpp 로컬 모델 전용 | 실행 위치·전송 경계를 명확히 구분 |
| 문항 생성 | 서버 RAG·제공자 호출 | 로컬 RAG·loopback 호출 | 같은 생성 조건·진행 단계·추가 지시문 |
| 검수·승인 | 서버 이력 | 로컬 SQLite 이력 | 같은 근거 카드·승인·수정·반려 |
| 내보내기 | 서버에서 생성한 CSV | 로컬에서 생성한 CSV | 같은 열·근거 식별자 형식 |

## 제공자별 실행 경계

| 모드 | AI 실행 | 자료·문항 전송 | 핵심 안내 |
|---|---|---|---|
| 관리형 AI | 서비스 서버 | 서비스 운영 범위 내 처리 | 기본 사용 경로 |
| 개인 외부 API | 제공자 API | 요청별 전송 동의 후 전송 | 전송 범위 미리보기 필수 |
| 로컬 AI | 교사 PC의 Ollama/llama.cpp | PC 밖으로 전송하지 않음 | 데스크톱 앱·loopback bridge 필요 |

### 초기 로컬 배포 정책

초기 설치형 로컬 앱은 **Ollama·llama.cpp 등 교사 PC에서 실행되는 로컬 모델만** 제공한다. Gemini·OpenAI·Claude 등의 개인 외부 API 입력·저장·선택 항목은 로컬 화면에서 노출하지 않으며, 로컬 번들은 외부 AI 제공자 호출 경로를 갖지 않는다. 모델 파일을 처음 준비할 때의 다운로드와 교사가 직접 여는 공식 자료 링크는 별개이며, 문항 생성에 사용되는 자료·프롬프트·문항 내용은 로컬 모델 실행 시 PC 밖으로 전송하지 않는다.

외부 개인 API는 향후 별도 선택 기능으로만 재도입한다. 재도입 전에는 제공자별 요청 범위 미리보기, 요청별 명시 동의, 자동 제공자 전환 금지, 키의 OS 보안 저장소 분리, 외부 전송 이력, 보안·운영 검토가 모두 충족되어야 한다.

## 공통 UI 구현 원칙

1. 웹 React 화면을 공통 UI 패키지로 유지하고, 데스크톱 셸은 동일한 화면을 감싼다.
2. 웹 tRPC 호출과 로컬 bridge 호출은 동일한 도메인 입력·출력 계약을 사용한다.
3. UI에는 OCR·RAG 같은 구현 용어 대신 자료 읽기, 근거 확인, 문항 생성, 검수 같은 교사 용어를 사용한다.
4. 제공자 선택만 달라져야 하며, 로컬이라는 이유로 기능·근거·검수 정보를 줄이지 않는다.
5. 새 기능은 아래 동등성 점검표에 웹·로컬 상태를 함께 기록한다.

## 동등성 점검표

| 기능 | 웹 | 로컬 기반 | 설치형 UI 출시 조건 |
|---|---|---|---|
| 자료·기출 등록 | 구현 | SQLite·local-only 기반 | 동일 등록 화면 연결 |
| 원본 PDF 대조 | 구현 | 파일 URL/위치 계약 | 로컬 PDF 뷰어 연결 |
| 제공자 선택 | 구현 | Ollama·llama.cpp bridge | 로컬 전용 선택 화면 연결 |
| 개인화 지시문 | 구현 | 공통 프롬프트 계약 | 로컬 설정 저장 연결 |
| 문항 생성·검증 | 구현 | bridge 생성 기반 | 공통 결과 저장 연결 |
| 검수·승인 | 구현 | 이력 저장 기반 | 공통 검수 UI 연결 |
| CSV 내보내기 | 구현 | CSV 저장 기반 | 공통 열 검증 |

이 문서는 이후 변경마다 업데이트하며, ‘웹만 구현’ 또는 ‘로컬만 구현’ 상태가 생기면 그 차이를 사용자에게 분명히 알린다.
