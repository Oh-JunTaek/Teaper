# Android alpha.13 설계 기준

대화는 앱 전용 `SharedPreferences`에 `LocalChatThread`와 메시지 목록으로 저장되며, 새 스레드의 제목은 첫 사용자 메시지 42자로 자동 지정되고 있다. alpha.13에서는 이 기본 동작을 기기 내 규칙 기반 제목 추천으로 바꾸고, 대화 선택 창에서 교사가 제목을 직접 수정할 수 있게 한다. 모델 응답을 추가 요약 호출로 처리하지 않아 성능·발열 위험을 늘리지 않는다.

채팅 모델의 컨텍스트 버퍼는 2,048토큰으로 계속 제한한다. 사용자가 요청한 무제한 답변 시험은 `sendMessage`의 답변 상한 인자를 전달하지 않는 호출 경로로 한 번만 열며, S25+에서 종료·발열·메모리 상태를 별도로 확인한다. 이 시험은 안정성 확인 전의 기본 정책으로 승격하지 않는다.

프롬프트 추출 방어는 모델 시스템 지시문만으로 충분하지 않으므로, 입력 차단과 생성 결과 저장 전 검사라는 두 단계 방어를 유지한다.

LiteRT-LM 0.16.1의 동기 `sendMessage(String)` 오버로드는 호출별 토큰 상한을 생략할 수 있다. alpha.13의 무제한 시험은 이 오버로드만 사용하며, 엔진의 2,048토큰 컨텍스트 버퍼는 변경하지 않는다. 따라서 답변의 절대 길이는 모델 기본 생성 정책과 남은 컨텍스트에 의해 제한된다.

현재 Android 자료 준비 화면은 자료 종류마다 ‘직접 작성’과 ‘파일에서 추가’ 버튼을 따로 나열한다. 통합 후에는 먼저 자료 종류를 고르고, 다음 단계에서 `직접 작성` 또는 `파일 불러오기`를 고르게 한다. 공식 자료의 원문 제공처는 앱 내부에 고정된 공식 URL 목록으로 제공하고, 사용자가 명시적으로 외부 브라우저를 열 때만 이동시킨다.

alpha.13은 Android 단위 테스트와 Debug APK 조립을 통과했다. 무제한 답변은 모델 기본 생성 상한을 그대로 사용하는 **실험 경로**이므로, S25+에서 긴 응답·후속 질문·앱 재시작을 묶어 강제 종료·발열·응답 지연을 확인한 뒤에만 기본값 여부를 결정한다.
