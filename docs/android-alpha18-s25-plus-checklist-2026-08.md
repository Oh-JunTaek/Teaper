# Android alpha.18 · 자료실과 대화 기록 확인

## 자료 준비

1. 홈에서 **자료 준비**를 누르면 팝업이 아니라 전용 자료실 화면으로 이동하는지 확인한다.
2. 전용 화면에서 **직접 작성**과 **파일 업로드**가 보이며, 업로드를 선택한 뒤에만 파일 선택 화면이 열리는지 확인한다.
3. **공식 자료 찾아보기**의 세 제공처를 누르면 외부 브라우저가 열리는지 확인한다.
4. 버튼이 빈 사각형으로 보이지 않고 텍스트·여백·대비가 읽기 편한지 확인한다.

## 대화 기록

1. 과거 대화 목록을 열었을 때 첫 인사 대신 최근 의미 있는 사용자 질문을 제목으로 보여 주는지 확인한다.
2. 대화 카드의 **편집**을 눌러 제목을 저장한 뒤, 목록을 닫고 다시 열어도 제목이 유지되는지 확인한다.
3. **현재 대화 삭제** 뒤 새 대화가 열리고 삭제한 대화가 목록에서 사라지는지 확인한다.
4. 대화 기록 카드와 편집 팝업의 색·대비·버튼이 채팅 화면과 일관되는지 확인한다.
