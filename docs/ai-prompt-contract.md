# AI 제공자 공통 프롬프트 계약

## 목적

관리형 AI, 개인 Gemini/OpenAI 호환 API, 로컬 Ollama는 같은 요청에도 문장 표현과 오류 양상이 다를 수 있다. 서비스는 이를 없애기보다 **근거 사용, 기출 비복제, 정답 검증, JSON 출력 형식**을 공통 계약으로 강제해 결과의 최소 품질 기준을 일정하게 유지한다.

## 적용 규칙

| 구분 | 공통 규칙 | 제공자별 차이 허용 범위 |
|---|---|---|
| 생성 | 근거 밖 사실 금지, 기출 실질 복제 금지, 하나의 정답, 그래프·표 실제 자료 사용 | 문장 표현, 예시의 순서, 설명의 간결성 |
| 검증 | 단원·지침·정답·해설·유사도 독립 확인, 모호하면 보수적 판정 | 모델별 분석 표현, 응답 속도 |
| 출력 | JSON 스키마 준수, 불필요한 Markdown 금지 | Ollama·Gemini·호환 API별 형식 보강 문장 |
| 기록 | 프롬프트 계약 버전, 제공자, 모델, 전송 동의 시각 저장 | 모델의 내부 추론 내용은 저장하지 않음 |

## 코드 위치와 운영 원칙

실제 계약은 `server/services/assessmentPrompt.ts`에 있으며, 현재 버전은 `chem-rag-v1.1`이다. 버전을 바꾸면 `CHANGELOG.md`에 이유·변경 규칙·비교 결과를 기록한다. 새 로컬 모델을 허용하기 전에는 동일한 화학 I 평가 세트로 관리형 모델과 비교해, 범위 이탈·정답 불일치·유사도·교사 수정량을 확인한다.

> 프롬프트는 품질을 보조하는 장치일 뿐, 교사의 최종 검수와 자동 검증을 대체하지 않는다.
