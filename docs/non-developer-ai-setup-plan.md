# 비개발자 교사를 위한 AI 설정 간소화 계획

## 목표

현재 AI 제공자 설정은 API 키, 모델명, 주소 등 기술 용어가 많아 처음 쓰는 교사에게 부담이 된다. 다음 단계에서는 기본값을 **관리형 AI**로 유지하면서도, 개인 API와 로컬 AI를 선택할 때 필요한 정보만 순서대로 묻는 방식으로 바꾼다.

| 단계 | 교사가 보는 흐름 | 시스템이 처리하는 내용 |
|---|---|---|
| 1. 기본 사용 | `바로 시작하기` | 관리형 AI를 기본 선택하고 비용·전송 원칙만 안내 |
| 2. 개인 API | `내 API 사용하기` → Google AI Studio 또는 OpenAI 호환 중 선택 | 제공자별 기본 주소·권장 모델을 자동 입력하고 키만 받음 |
| 3. 연결 확인 | `연결 확인` | 키를 암호화 저장하고 간단한 상태 결과만 표시 |
| 4. 로컬 AI | `내 PC에서만 사용하기` | 데스크톱 앱 설치 여부·모델 준비·하드웨어 상태를 순서대로 안내 |
| 5. 문제 해결 | `도움이 필요합니다` | 오류 원인, 해결 순서, 관리형 AI로 돌아가기 제공 |

## 화면 문구 원칙

`API 키`, `엔드포인트`, `모델 ID` 대신 `개인 AI 연결`, `서비스 선택`, `사용할 모델`처럼 목적 중심의 언어를 쓴다. 고급 설정은 기본 화면에서 숨기고, 필요한 사람만 열 수 있게 한다. 외부 전송 동의는 기술 용어가 아니라 **어떤 자료가 어디로 전송되는지**를 먼저 보여 준 뒤에 받는다.

## 다음 구현 순서

1. 관리형 AI 기본 카드와 개인 API 연결 마법사를 구현한다.
2. Gemini·OpenAI 호환 제공자의 권장 기본값을 선택형으로 제공한다.
3. 오류 메시지를 교사용 문장으로 정리하고 관리형 AI로 돌아가기 버튼을 제공한다.
4. 데스크톱 로컬 앱 출시 시 loopback 브리지의 설치·상태 확인을 같은 마법사에 연결한다.
