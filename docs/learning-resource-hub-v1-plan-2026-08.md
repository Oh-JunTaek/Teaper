# 수업 자료 활용 허브·가상 실험 검토 메모

**작성일:** 2026-08-28  
**목적:** 교사가 수업에 필요한 자료를 빠르게 찾고 열람·활용하도록 돕는 기능의 Version 1 범위를 정하고, 가상 실험을 문제 출제 워크스페이스와 분리할지 판단한다.

> **결론:** Version 1에서는 자료를 복제·호스팅하거나 AI가 자동 생성하는 방식보다, 과목·학교급·단원별로 선별한 공식·라이선스 확인 자료를 **찾고, 원문에서 열고, 교사 작업 공간에 연결하는 허브**를 우선한다. 가상 실험은 교육적 가치가 높지만 콘텐츠 정확성, 기기 호환, 상업 이용 라이선스와 학습 데이터 관리 범위가 달라 별도 서비스 또는 별도 모듈로 검토한다.

## 1. 확인한 자료 출처와 운영 의미

에듀넷은 한국교육학술정보원 서비스로 교육정책·학습·평가 자료 등을 제공하며, 교사가 원문 출처로 이동하는 연결 허브의 우선 출처로 적합하다.[1] 다만 개별 자료의 이용 조건과 로그인·연계 방식은 자료별로 다시 확인해야 하므로, Version 1은 원문 URL·출처·이용 메모를 보여 주고 파일을 서비스에 복제하지 않는다.

PhET의 일반 HTML 시뮬레이션은 CC BY-NC 4.0으로 제공된다. 교육자가 비상업적으로 수업에서 쓰는 것은 가능하지만, 유료·구독·광고 기반 제품에 포함하는 등 상업적 이익이나 금전 보상이 있는 사용은 상업 사용으로 보며 별도 라이선스가 필요할 수 있다. 재배포 시에는 지정된 출처 표기를 사용 지점 가까이에 사람이 읽을 수 있게 표시해야 한다.[2]

| 자료 유형 | Version 1에서 제공하는 방식 | 저장·저작권 원칙 |
|---|---|---|
| 교육과정·공식 안내 | 과목·학교급·단원 필터, 원문 열기, 출처 메모 | 현재처럼 링크·메타데이터 우선, 원문 일괄 복제 금지 |
| 수업·학습·평가 자료 | 교사가 신뢰 출처 필터·키워드로 찾고 새 탭에서 원문 열기 | 출처·저작자·이용 조건·확인일 표시, 계정 우회·무단 수집 금지 |
| 교사 개인 자료 | 기존 자료 준비에 링크 또는 파일을 명시적으로 연결 | 교사가 업로드 권한을 확인, 외부 AI 전송은 별도 동의 |
| 외부 가상 실험 | 단원 카드에서 원문으로 열기와 수업 활용 메모 제공 | 서비스 내 복제·임베드·스크린샷 사용 전 개별 라이선스 확인 |

## 2. 자료 활용 허브 Version 1 제안

교사는 ‘자료를 찾는 일’과 ‘문항의 근거로 쓰는 일’을 분리해서 판단할 수 있어야 한다. 따라서 새 메뉴는 **수업 자료 찾아보기**로 제안한다. 이 메뉴는 기존 자료 관리와 연동하되, 처음에는 교사가 직접 검색한 외부 원문을 편하게 열고 선택적으로 작업에 연결하는 도구다.

| 순서 | 교사 경험 | Version 1 기능 | 구현·운영 경계 |
|---|---|---|---|
| 1 | 학교급·과목·단원 선택 | 중등/고등 → 과학/수학 → 단원 필터 | 교육과정 카탈로그 메타데이터만 사용 |
| 2 | 필요한 자료 종류 선택 | 개념 설명, 활동지, 시청각 자료, 평가 보조, 가상 실험 링크 | 자료 유형·난이도·수업 시간 태그 |
| 3 | 짧은 이유를 보고 원문 열기 | 자료 제목·출처·설명·이용 메모·확인일·원문 열기 | 콘텐츠 전문을 자동 복제하지 않음 |
| 4 | 수업에 쓸 자료를 작업에 연결 | ‘내 자료에 링크 추가’ 또는 ‘문항 근거로 선택’ | 연결 전 교사 확인, 외부 AI 전송과 분리 |
| 5 | 다음에도 다시 활용 | 즐겨찾기·수업 메모·최근 열람 | 개인 메모는 작업공간/기기에 저장, 열람 이력은 외부 통계로 전송하지 않음 |

Version 1의 핵심 성공 기준은 검색 결과 수가 아니라, 교사가 한 단원에서 신뢰할 수 있는 자료를 **두세 번의 선택 안에 열고**, 본인 수업 자료 또는 문항 생성 근거로 명시적으로 연결할 수 있는지다. 콘텐츠 수집·추천의 자동화는 이 동선과 출처 메타데이터 품질을 확인한 뒤 Version 1.1에서 검토한다.

## 3. 가상 실험의 분리 판단

가상 실험은 단순 링크 모음보다 실험 조건 설정, 결과 해석, 오개념 피드백, 접근성, 기기 성능, 학생 데이터 처리까지 포함하는 학습 경험이다. 문제 출제 워크스페이스의 ‘교사 검수 후 문항·자료 출력’ 모델과 성공 기준이 다르므로 Version 1의 핵심 기능으로 묶지 않는 편이 안전하다.

| 선택지 | 장점 | 주요 위험·비용 | 권고 |
|---|---|---|---|
| 외부 가상 실험 링크 허브 | 빠른 도입, 자체 실험 엔진 불필요 | 상업 이용 라이선스·링크 안정성·출처 표시 관리 | **자료 허브 Version 1에 포함 가능** |
| 외부 시뮬레이션 임베드 | 수업 화면을 한곳에서 유지 | CSP·로그인·광고·쿠키·모바일 호환·라이선스 책임 | Version 1 제외, 공급자별 계약 후 검토 |
| 자체 가상 실험 제작 | 교육과정에 맞는 통제와 문항 연동 | 과학적 검증, 실험 안전·오해 방지, 콘텐츠 제작·QA, 유지보수 부담 | **별도 서비스/별도 예산으로 타당성 검토 후 착수** |

특히 PhET를 향후 교사 플러스 등 유료 플랜과 함께 제공하는 것은 ‘유료·구독 기반 제품에 포함’될 수 있으므로, 링크만 제공하는 경우에도 실제 사업 구조에 맞춘 권리자 문의 또는 상업 라이선스 검토가 필요하다.[2] 이 판단은 법률 자문이 아니며, 실제 공개 전에 계약·저작권 담당자 또는 전문가가 확인해야 한다.
