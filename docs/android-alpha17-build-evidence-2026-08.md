# Android alpha.17 빌드 검증 기록

## 자동 검증 결과

`testDebugUnitTest`는 저메모리 Gradle 실행에서 `BUILD SUCCESSFUL`로 완료되었다. 동일 소스의 Debug APK 조립도 `BUILD SUCCESSFUL`을 확인했다. 빌드 데몬 종료 메시지는 조립 완료 뒤 단일 사용 데몬을 종료하는 과정에서 발생했으며, 소스 컴파일·단위 테스트·APK 산출물은 완료 로그로 별도 확인했다.

## APK 식별 및 S25+ 확인

alpha.17은 문항 생성 카드의 즉시 요청 화면, CPU 안정성 모드의 실행 시점 모델 준비, 자료 추가 안의 직접 작성·파일 업로드, 공식 자료 외부 링크, 칠판 기반 맞춤 팝업·홈·채팅 화면을 포함한다. 실기기에서는 문항 생성 카드 반응, 자료 추가 단계, 공식 링크, 팝업 대비·여백, 긴 채팅 후 종료 재발 여부를 확인해야 한다.
