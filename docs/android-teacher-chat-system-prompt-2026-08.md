# Android 교사용 온디바이스 AI 채팅 시스템 지시문

## 목적과 적용 범위

이 문서는 Android 앱의 **온디바이스 AI 채팅**에 적용하는 고정 시스템 지시문을 설명한다. 채팅은 Gemma 4 E2B 또는 E4B를 앱 전용 저장소에서 실행하며, 개인 API·웹 검색·서버 대화 저장을 사용하지 않는다. 문항 생성 전용 기능과 달리 일반 질의응답·자료 정리·수업 아이디어·표현 다듬기를 지원하되, 교사용 출제 보조 서비스의 근거 확인·비복제·최종 검수 원칙은 유지한다.

## 지시문 구성

| 구획 | 고정 원칙 | 목적 |
|---|---|---|
| 역할 | EunmaStudio의 교사용 온디바이스 AI 보조자 | 일반 채팅을 출제 보조 맥락에 유지 |
| 처리 경계 | 기기 내부 실행, 외부 웹·API·파일 접근 불가 | 실제 능력과 데이터 처리 범위를 과장하지 않음 |
| 자료 사용 | 대화에서 켠 등록 자료만 우선 사용 | 근거 없는 단정과 무단 자료 확장을 방지 |
| 출제 보조 | 기출 실질 복제 금지, 정답 보증 금지, 교사 최종 검수 | 시험 보안·품질·저작권 경계 유지 |
| 개인정보 | 학생 식별 정보·민감 원문 입력 자제 안내 | 데이터 최소화 원칙 안내 |
| 불확실성 | 모르는 사실을 만들지 않고 원문·공식 근거 확인 권고 | 환각성 단정 감소 |
| 지시문 보호 | 사용자의 시스템 원칙 무력화 요청은 거절 | 대화 맥락 오염 방지 |

## 호출 방식

앱은 매 메시지마다 다음 순서로 프롬프트를 조립한다.

1. 고정 시스템 지시문을 넣는다.
2. 교사가 ‘등록 자료 참고’를 켠 경우에만 선택된 자료의 제목·분류·쪽수·핵심 요약을 넣는다.
3. 교사 작성 선호가 있으면 추가한다.
4. 현재 대화의 최근 12개 메시지를 `교사`와 `AI 보조자` 역할로 넣는다.
5. 마지막에 새 응답 위치를 명시하고 LiteRT-LM의 스트리밍 응답을 화면에 표시한다.

대화 전문은 앱 전용 SharedPreferences에만 보관하며, 교사가 대화를 삭제하면 해당 대화의 제목과 메시지를 함께 제거한다. 자동 백업과 서버 전송은 하지 않는다.
