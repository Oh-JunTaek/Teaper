# 교사용 문제집형 PDF 내보내기 유료 옵션 제안서

**작성일:** 2026-08-22  
**제안 대상:** EunmaStudio 교사도우미의 웹·Windows·Android 출력 기능  
**전제:** 교사가 검수한 문항을 수업·평가용 문서로 편집하는 시간을 줄이는 기능을 유료화하되, 자료 보안·데이터 이동·기본 접근성을 유료 장벽으로 만들지 않는다.

> **권고:** 문제집형 PDF 내보내기는 좋은 유료 옵션입니다. 다만 ‘PDF 버튼 하나’를 유료화하기보다, 교사가 실제로 시간을 절약하는 **문제집 구성·서식·정답지 분리·인쇄 점검·버전 관리**를 하나의 ‘출력 완성도’ 상품으로 제공하는 편이 설득력이 높습니다. 이미 제공 중인 기본 CSV/DOCX/단순 인쇄 흐름은 유지하고, 더 완성된 교사용 결과물을 유료 기능으로 분리하는 것이 바람직합니다.

## 1. 왜 유료화 가치가 있는가

문항 생성 자체보다 교사가 실제로 반복하는 일은 ‘승인 문항을 골라 시험지·학습지로 배열하고, 배점·여백·정답지·페이지 번호를 확인해 출력 가능한 형태로 만드는 일’입니다. 이 과정은 단순 파일 변환보다 교사의 편집 시간을 직접 줄이는 가치가 있습니다.

현재 웹과 Windows에는 문서·인쇄형 출력 기반이 있고, Android는 수업 직전 현장형 사용에 더 가깝습니다. 따라서 유료 옵션은 AI 호출량이 아니라 **검수 완료 문항을 안전하고 보기 좋게 묶는 문서 생산성**을 중심으로 설계하는 것이 서비스 정체성과도 맞습니다.[1] [2]

## 2. 무료와 유료의 권장 경계

| 구분 | 무료 기본 | 유료 ‘문제집 출력’ 옵션 | 이유 |
|---|---|---|---|
| 문항 생성·검수 | 자료 기반 생성, 교사 검수, 상태 변경 | 동일 | 핵심 교육 보조 기능을 막지 않음 |
| 데이터 접근·백업·이관 | 기본 내보내기, 암호화 이관, 삭제 | 동일 | 교사 자료의 이동·삭제 권리를 유료 장벽으로 만들지 않음 |
| 기본 출력 | CSV, 간단 DOCX, 단순 인쇄/PDF | 동일하게 유지 | 이미 사용 중인 흐름을 후퇴시키지 않음 |
| 문제집 편집 | 최소 순서 변경·문항 선택 | 표지, 단원 구분, 번호 체계, 배점 표기, 학생 이름/학급란, 여백·줄간격, 2단/1단, 페이지 나눔 | 교사가 체감하는 시간 절감 가치 |
| 정답·해설 | 기본 답안 확인 | 학생용/교사용 분리 PDF, 해설 별책, 채점용 답안지, 문항별 근거 목록 | 출력물 품질과 업무 완성도 가치 |
| 인쇄 품질 | 기본 브라우저 인쇄 | A4/양면/제본 여백 검사, 잘림 경고, 미리보기, 인쇄용 표·그래프 최적화 | 현장 오류를 줄이는 프리미엄 가치 |
| 재사용 | 단일 문서 출력 | 학교/학급별 템플릿 저장, 학기별 표지·머리말, 출력 이력·버전 비교 | 반복 업무 자동화 가치 |

**핵심 원칙은 ‘교사의 문항·자료를 인질로 잡지 않는다’는 점입니다.** 기본 데이터 접근, 삭제, 암호화 이관, 최소 내보내기는 무료로 남겨야 합니다. 유료 기능은 그 데이터를 더 편하게 구성하고 인쇄 가능한 품질로 만드는 시간 절약 도구여야 합니다.

## 3. 상품 이름과 제공 경험

기능 이름은 ‘유료 PDF’보다 **문제집 출력** 또는 **교사용 출력 패키지**가 낫습니다. 교사는 파일 형식보다 결과물을 원하기 때문입니다.

### 권장 MVP: 문제집 출력 패키지

교사가 승인 문항을 고른 뒤 다음 다섯 단계로 작업합니다.

| 단계 | 기능 | 교사에게 보이는 결과 |
|---|---|---|
| 1. 문항 선택 | 승인 문항·쪽지시험 세트 선택, 단원별 그룹화 | 출력할 문항 목록과 누락된 검수 상태 경고 |
| 2. 문서 구성 | 표지·학급/이름·시험 시간·총점·유의사항·문항 번호·배점 | ‘학습지’, ‘쪽지시험’, ‘중간평가’ 등 템플릿 선택 |
| 3. 답안 구성 | 학생용, 정답지, 해설지, 채점용 답안지 선택 | 서로 다른 PDF를 한 번에 생성 |
| 4. 인쇄 점검 | A4·양면·제본 여백·표/그래프 잘림·빈 페이지 점검 | 문제 있는 문항과 페이지를 사전 안내 |
| 5. 출력 이력 | 생성 시각·문항 구성·문서 버전 기록 | ‘2026-2 화학 I 1차 쪽지시험 v2’처럼 재출력 |

## 4. 플랫폼별 제공 방식

| 플랫폼 | 권장 범위 | 유료 적용 방식 | 비고 |
|---|---|---|---|
| 웹 | 문제집 편집기, PDF 생성, 템플릿 저장, 출력 이력 | 구독 또는 월간 출력 패키지 | 서버에서 문서 조판·권한 확인 가능 |
| Windows 로컬 | 로컬 문서 조판, PDF/DOCX, 오프라인 인쇄 | 로컬 라이선스 또는 웹 구독의 오프라인 권한 캐시 | 문항·자료는 PC 밖으로 보내지지 않음 |
| Android | 문항 선택·간단 미리보기·보관함 전송·공유 | 초기에는 ‘문제집 출력 준비’까지만, 정식 조판은 웹/Windows | 작은 화면에서 복잡한 편집기를 강제하지 않음 |

Android에서 처음부터 모든 PDF 편집 기능을 구현하는 것은 권장하지 않습니다. Android는 수업 직전 문항 확인, 쪽지시험, 자료·메모 수집, 출력 준비에 집중하고, 실제 조판은 웹 또는 Windows에서 수행하게 하면 플랫폼의 강점을 살릴 수 있습니다. 이후 사용 패턴이 확인되면 Android에는 ‘학생용 PDF 간편 생성’만 별도로 추가할 수 있습니다.

## 5. 과금 방식 비교

| 방식 | 장점 | 주의점 | 권고 |
|---|---|---|---|
| 월 구독 | 템플릿·저장·재출력 등 반복 가치와 잘 맞음 | AI 호출 비용과 문서 기능을 한 요금에 섞으면 이해가 어려움 | **주력 후보** |
| 출력 횟수 패키지 | 가끔 시험지를 만드는 교사에게 진입이 쉬움 | 출력 직전에 결제 압박으로 느껴질 수 있음 | 보조 옵션 |
| Windows 영구 라이선스 | local-only를 선호하는 교사에게 명확함 | 업데이트·지원 비용을 별도 설계해야 함 | 로컬 전용 보조 옵션 |
| AI 생성 크레딧과 묶기 | 결제 체계 단순화 가능 | PDF 편집 가치와 AI 사용량이 혼동됨 | 초기에는 분리 권장 |

### 권장 상품 구조

1. **무료:** 자료 준비, 생성·검수, 기본 CSV/DOCX/인쇄, 데이터 이관·삭제.
2. **출력 패키지:** 문제집 템플릿, 학생용·교사용 분리 PDF, 인쇄 점검, 출력 이력, 템플릿 저장.
3. **기관 옵션:** 학교 공통 서식, 표지 규칙, 기관 로고, 감사용 출력 이력, 다수 교사 관리.

가격은 실제 교사 인터뷰에서 ‘월간 시험지/학습지 출력 횟수’, ‘기존 문서 편집 시간’, ‘학교 예산 또는 개인 결제 가능성’을 확인한 뒤 결정하는 것이 적절합니다. 지금 단계에서는 가격을 고정하기보다, **출력 패키지가 실제로 절약한 편집 시간**을 먼저 측정해야 합니다.

## 6. 권리·보안·운영 통제

| 위험 | 필요한 통제 |
|---|---|
| 기출·외부 자료의 무단 복제 | 출력 전 ‘교사가 권리·이용 범위를 확인했다’는 고지, 원문 대량 복제 방지, 출처·페이지 근거 유지 |
| 출시 예정 문항 유출 | 출력물의 선택적 워터마크, 문서 생성 이력, 공유 전 경고, 자동 공개 링크 금지 |
| AI 오류가 포함된 배포물 | ‘승인 문항만 출력’, 답·해설·배점 불일치 경고, 교사 최종 검수 확인 |
| 교사 데이터 종속 | 기본 데이터 내보내기·암호화 이관·삭제를 유료 여부와 무관하게 제공 |
| 결제 후 기능 차단 혼란 | 결제 화면에 포함 기능·월간 한도·갱신일·해지 뒤 보존되는 데이터 명시 |
| PDF 생성 비용 급증 | 문서 조판 기능과 AI 생성 비용을 분리 측정하고, 대량 생성은 기관 플랜에서 제한·승인 |

유료 옵션을 출시하기 전에는 실제 이용약관·개인정보 처리방침·결제/환불 안내·저작권 고지·보존/삭제 정책을 운영 조건에 맞게 검토해야 합니다. 이는 제품 설계 제안이며, 계약·결제·저작권 적용의 최종 판단은 관련 전문가 검토가 필요합니다.

## 7. 출시 순서 권고

| 순서 | 범위 | 성공 기준 |
|---|---|---|
| 0. 안정화 | Android 쪽지시험·모델 설정, 웹/Windows 기본 출력 검증 | 생성·검수·기본 출력이 안정적으로 작동 |
| 1. 무료 베타 | 웹·Windows에서 승인 문항 선택 → 기본 문제지/정답지 PDF 생성 | 교사가 실제 수업에 사용하고 편집 시간 피드백 확보 |
| 2. 유료 베타 | 3~5개 템플릿, 학생/교사용 분리, 인쇄 점검, 출력 이력 | 유료 기능이 기본 출력보다 명확히 편리하다는 피드백 확보 |
| 3. 정식 | 구독/출력 패키지, 기관 서식, 고객 지원·정책 | 결제·해지·데이터 보존·권리 고지가 실제 운영 가능 |

## 8. 최종 권고

**문제집형 PDF 내보내기는 유료화의 좋은 첫 후보입니다.** 다만 단순 PDF 다운로드가 아니라, 교사가 승인 문항을 ‘배포 가능한 문제지’로 바꾸는 전 과정을 완성하는 기능으로 설계해야 합니다. 무료 사용자는 생성·검수·기본 출력·자료 이동을 계속 할 수 있고, 유료 사용자는 조판·템플릿·정답지 분리·인쇄 점검·재사용으로 시간을 절약한다는 구도가 가장 건강합니다.

첫 개발 범위는 **웹과 Windows의 문제집 출력 패키지**를 우선하고, Android는 문제 선택·출력 준비·공유로 연결하는 것이 적절합니다. 결제 연동 자체는 출력 경험과 교사 가치가 검증된 뒤에 붙이는 편이 리스크가 낮습니다.
