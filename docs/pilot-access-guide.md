# 파일럿 참여자 접근 안내

교사도우미는 현재 공개 배포가 아닌 **공유 링크 파일럿**으로 운영한다. 참여자에게는 서비스 주소 뒤에 초대 코드를 붙인 링크를 전달한다. 초대 코드는 서버 전용 비밀값이며, 이 문서나 GitHub 저장소에 기록하지 않는다.

```
https://teachassist-agafjffs.manus.space/?invite=초대코드
```

링크를 연 참여자는 먼저 파일럿 접근이 확인된 뒤 두 가지 방식 중 하나를 선택한다. 개인 Google 로그인은 이용자별 작업공간과 개인 AI 제공자 설정을 분리한다. 게스트 로그인은 ID `guest`로 제공하는 1인 테스트용 공용 작업공간이다. 따라서 게스트로 올린 참고 자료·기출·문항·검수 이력은 같은 게스트 계정을 사용하는 사람에게 보일 수 있으며, 출시 예정 문항이나 개인 API 키를 게스트 계정에 넣으면 안 된다.

| 운영 항목 | 파일럿 기준 |
|---|---|
| 공유 대상 | 초대 코드가 포함된 링크를 받은 제한된 참여자 |
| 게스트 계정 | ID `guest`, 서버 전용 비밀번호, 최대 12시간 세션 |
| 공유 링크 세션 | 서버 서명 쿠키, 최대 7일 |
| 개인 자료·문항 | Google 로그인 사용 시 이용자별로 분리 |
| 게스트 자료·문항 | 게스트 계정 사용자끼리 공유될 수 있음 |
| 초대 코드 교체 | 링크가 의도치 않게 공유되었거나 파일럿 종료 시 즉시 교체 |

파일럿 종료 또는 링크 유출이 의심되면 `PILOT_ACCESS_CODE`를 새 값으로 바꾸고, 필요하면 `GUEST_LOGIN_PASSWORD`도 함께 교체한다. 교체 후 기존 브라우저의 접근 쿠키는 즉시 무효화되지 않을 수 있으므로, 보안 사고 대응에서는 서비스 배포 재시작·운영 기록 확인·게스트 작업공간 자료 검토를 함께 수행한다.
