# 공식 자료·중등 수학 계산 확인·과목 준비 상태 안내

## 공통 공식 자료

학교급·교과·과목을 고르면 해당 과목 문서와 함께 아래 공통 공식 자료가 표시된다. 문서는 원문을 서비스에 복제하지 않고, 공식 링크와 메타데이터로 제공한다.

| 자료 | 활용 목적 | 출처 |
|---|---|---|
| 2022 개정 교육과정 총론 | 학교급별 적용 시기와 공통 운영 기준 확인 | 교육부 고시 제2022-33호 |
| 성취기준·평가기준 | 문항의 학습 범위·평가 요소 확인 | KICE 학생평가지원포털 |
| 학생평가 도구 | 수행평가·서논술형·채점기준 설계 참고 | KICE 학생평가지원포털 |
| 성취수준 자료 | 기대 성취 수준·평가기준 확인 | 에듀넷 |

공통 문서도 교사별로 ‘출제 기준에 포함’ 여부를 선택한다. 선택된 공통 문서는 해당 과목 생성 요청의 공식 자료 기록에 함께 남는다.

## 중등 수학 계산 확인기

중등 수학 문항 중 수치 계산, 일차식, 비례, 평균·중앙값을 포함한 문항은 생성 시 계산용 식과 수치 정답을 함께 받는다. 서비스는 동적 코드 실행 없이 제한된 계산식만 해석해 문항 정답과 대조한다.

| 결과 | 의미 | 다음 행동 |
|---|---|---|
| 일치 | 계산 결과와 문항 정답이 동일 | 해설·조건을 교사가 계속 검수 |
| 불일치 | 계산 결과와 문항 정답이 다름 | 자동 검증 보류, 식·조건·정답 수정 필요 |
| 교사 확인 필요 | 식 형식·범위가 계산 확인기 대상 밖 | 직접 풀이와 학교 자료 대조 필요 |
| 대상 아님 | 계산 대조가 필요한 문항이 아님 | 일반 검수 흐름 유지 |

> 계산 확인기는 정답의 수치 일치만 대조한다. 문장 해석, 조건 누락, 정의역, 교육과정 적합성, 난이도는 자동으로 확정하지 않으므로 교사 최종 검수가 필수다.

### 대표 단원 검수 묶음

계산 확인기 변경 시에는 실제 교사·학생 자료를 사용하지 않는 기초 산술 조건으로 회귀 검사를 실행한다. 현재 묶음은 유리수와 계산, 일차방정식, 비례식, 자료의 정리(평균)의 네 영역을 포함한다. 이 묶음의 통과는 계산기 기능의 후퇴를 탐지하는 최소 조건일 뿐이며, 중등 수학 전 범위의 문항 품질을 보증하지 않는다.

## 과목 준비 상태

| 상태 | 현재 과목 예시 | 생성 정책 |
|---|---|---|
| 파일럿 검증 | 화학 I | 기존 파일럿 흐름으로 생성 가능 |
| 제한 파일럿 | 중등 과학·수학, 통합과학1·2, 과학탐구실험1·2, 화학, 공통수학1·2 | 생성 가능하나 공식 문서·학교 자료·계산 결과의 교사 검수 필수 |
| 준비 중 | 대수, 미적분Ⅰ, 확률과 통계, 물리학, 생명과학, 지구과학 | 자료 등록·공식 문서 확인만 제공, 문항 생성은 서버에서도 차단 |

대수·미적분Ⅰ·확률과 통계는 2022 개정 교육과정 공식 문서 링크를 카탈로그에 먼저 제공한다. 이 문서는 범위 확인을 위한 준비 단계이며, 과목별 계산·조건 검수와 교사 검수 문항 묶음이 갖춰지기 전에는 제한 파일럿으로 올리지 않는다.

대시보드의 **준비 상태** 필터로 파일럿 검증, 제한 파일럿, 준비 중 과목을 분리해 확인할 수 있다. 필터는 선택 목록을 정리하는 기능일 뿐이며, 서버의 생성 차단 정책을 우회하지 않는다.
