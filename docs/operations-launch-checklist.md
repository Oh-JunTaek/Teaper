# EunmaStudio 교사도우미 운영 체크리스트

## 파일럿 유지 필수

- [ ] 운영 담당자와 보안·개인정보 문의 이메일을 정하고 서비스 화면에 게시한다.
- [ ] `PERSONAL_API_ENCRYPTION_KEY`를 운영용 무작위 키로 교체하고 복구·교체 책임자를 지정한다.
- [ ] 자료·문항·검수 이력·보안 로그·백업의 보관기간과 삭제/파기 방식을 확정한다.
- [ ] 학생 개인정보·출시 예정 문항의 외부 AI 전송 금지 안내를 자료 등록과 생성 화면에 다시 고지한다.
- [ ] 침해·저작권 삭제 요청·학교 보안 문의를 접수할 이메일과 1차 응답 목표 시간을 정한다.
- [ ] 3~5명 교사 파일럿에서 자료 등록, 원본 대조, 외부 전송 동의, 삭제, 내보내기, 오류 대응을 점검한다.

## 정식 공개 전 필수

- [ ] 개인정보 처리방침, 이용약관, 저작권/자료 이용 정책, AI 사용 고지를 실제 연락처·시행일·보유기간으로 확정한다.
- [ ] 외부 AI 제공자별 처리 위치·보관·학습 사용·국외이전·약관을 검토해 고지와 계약 근거를 확정한다.
- [ ] 비밀정보 스캔, 접근권한 검토, 의존성 취약점 점검, 백업·복구·침해 대응 모의훈련을 완료한다.
- [ ] 생성형 AI 고지·생성 이력·교사 최종 검수 원칙이 모든 문항 생성·내보내기 흐름에 표시되는지 확인한다.
- [ ] 서비스 상태·점검 공지·장애 이력·문의/이의 제기 경로를 제공한다.

## 기관 도입 또는 유료화 전 필수

- [ ] 기관별 관리자·교사·검수자 역할, 공동 작업, 감사 로그, 계정 수명주기, 조직 데이터 격리를 구현한다.
- [ ] 처리위탁/국외이전/DPA, 정보보안 부속합의, SLA, 데이터 반환·파기, 사고 통지 조항을 계약에 반영한다.
- [ ] 가격, 결제, 세금계산서, 해지, 청약철회·환불, 사업자·통신판매 정보, 분쟁처리를 정식 고지한다.
- [ ] 조직 단위 백업·재해복구·보안성 검토·침해 대응 연락망을 고객과 합의한다.
