# 교사도우미

**EunmaStudio**가 만드는 근거 기반 출제 보조 서비스입니다. 현재는 화학 I 파일럿으로 운영하며, 교사가 교육과정·수업 자료·기출 유형을 근거로 문항 초안을 만들고 검수하도록 돕습니다. 생성 결과는 시험지 완성본이 아니라 **교사가 반드시 검토해야 하는 초안**입니다.

## 교사용 빠른 시작

| 순서 | 할 일 | 확인할 점 |
|---|---|---|
| 1 | 로그인 후 대시보드를 엽니다. | 오늘의 출제 업무 카드에서 자료·기출·검수 건수를 확인합니다. |
| 2 | **참고 자료**에서 학교 평가계획, 수업 자료, 출제 지침을 등록합니다. | PDF·이미지 또는 웹 링크를 쓰며, 페이지·표·문항 번호는 `원본 위치`에 기록합니다. |
| 3 | **기출문제**에서 공식 제공처를 확인하고, 필요한 유형을 개인 작업공간에 등록합니다. | 원본 PDF를 연결할 수 있으며, 출처·연도·문항 번호·페이지를 입력합니다. |
| 4 | **문항 생성**에서 과목·단원·유형·난이도·배점을 선택합니다. | 외부 개인 AI를 쓰면 이번 요청의 전송 범위와 호출 수를 확인하고 동의합니다. |
| 5 | **검수함**에서 문제·그래프/표·근거 발췌·원본 위치·검증 결과를 확인합니다. | 승인·수정 승인·반려 중 하나와 검수 사유를 기록합니다. |
| 6 | **승인 문항**에서 최종 문항을 확인하고 CSV로 내보냅니다. | 실제 시험지 사용 전 교사가 최종 정답·해설·저작권을 확인합니다. |

## 자료와 기출문제 등록 원칙

교사가 등록한 참고 자료와 기출문제는 개인 작업공간에 분리됩니다. 참고 자료는 삭제할 수 있으며, 삭제 후 새 문항 생성에는 사용되지 않습니다. 기존 검수 이력에는 어떤 근거가 사용되었는지 확인할 수 있도록 최소한의 근거 스냅샷이 남습니다.

기출문제는 공식 제공처의 이용 조건과 저작권 고지를 먼저 확인한 뒤, 수업·검수에 필요한 범위에서 직접 등록하세요. 서비스는 공식 기출 원문을 일괄 복제하거나 다른 교사에게 자동 공유하지 않습니다. 원본 PDF를 연결할 때는 출처, 연도, 문항 번호, 문제지 페이지를 함께 입력하면 검수 근거가 명확해집니다.

## 그래프·표 문항 사용법

`그래프 해석형`을 선택하면 문항은 그래프 설명문 대신 축·단위·범례·좌표를 가진 SVG 그래프로 표시됩니다. 예를 들어 퍼텐셜 에너지 문항은 원자 간 거리와 퍼텐셜 에너지 축, X/Y 곡선을 실제로 보여 줍니다. `실험 자료형` 또는 표를 요구한 문항은 행·열을 가진 표로 표시됩니다. 그래프와 표의 과학적 정확성은 검수함에서 반드시 확인하세요.

## AI 실행 방식

기본값은 **관리형 AI**입니다. 별도 설정 없이 사용할 수 있으며, 개인 Gemini 또는 OpenAI 호환 API와 로컬 Ollama는 선택 기능입니다. 외부 개인 API를 사용하면 선택된 근거 발췌·출제 조건·추가 요구사항이 해당 제공자로 전송될 수 있으므로, 매 요청마다 전송 범위를 확인해야 합니다. 개인 API 키는 화면에 다시 표시되지 않으며 암호화하여 보관합니다.

## 문제 해결

| 증상 | 먼저 확인할 방법 |
|---|---|
| 한글 파일명이 업로드되지 않음 | 최신 배포본인지 확인한 뒤 다시 업로드합니다. 내부 저장 경로는 한글 파일명과 분리되어 있습니다. |
| 자료가 문항 생성에 반영되지 않음 | 과목·단원이 생성 요청과 같은지, 자료 내용 준비 상태가 완료인지 확인합니다. |
| 기출 원본이 보이지 않음 | PDF 연결은 본인이 등록한 기출에서만 표시됩니다. 출처·페이지도 함께 확인합니다. |
| 그래프가 의도와 다름 | 검수함에서 그래프의 축·단위·곡선·수치를 확인하고 문항을 수정 또는 반려합니다. |
| 개인 AI 연결이 어려움 | 우선 관리형 AI를 사용하고, 향후 추가될 간편 연결 화면을 이용합니다. |

## 개발·운영 문서

프로젝트 변경은 [CHANGELOG.md](./CHANGELOG.md)에 기록합니다. 아직 만들지 않은 기능과 운영 과제는 [todo.md](./todo.md)에서 확인합니다. 기능을 추가하거나 정책을 바꿀 때는 `Unreleased` 항목과 TODO를 함께 갱신하는 것을 원칙으로 합니다. 코드 검토 시에는 [기능별 코드 검토 안내](./docs/code-review-map.md)를 참고하세요.

> 운영 전에는 개인정보 처리방침, 이용약관, 자료 권리 확인, 보존·삭제 정책, AI 제공자 약관을 실제 운영 조건에 맞게 확정해야 합니다.
